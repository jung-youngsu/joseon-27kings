## 작업 메모

### 설계 (2026-10-17)

- **축:** 1330 "書我過失者，皆書生也"(내 잘못을 적는 것들은 다 서생들이다) + 권109 "王不能堪其言，踰墉而走"(그 말을 견디지 못해 담을 넘어 달아났다) → 꾸중 속에서 자란 사람이 아픈 말을 피하고 맞장구치는 사람을 곁에 두었다. 마지막에 믿은 것도 꾸짖지 않던 얼굴(고룡보).
- **후렴:** 이조년 "殿下孰從而聞正言見正事乎"(전하께서 어디서 바른말을 듣고 바른 일을 보셨겠습니까) — 왕을 꾸짖으면서 그가 자란 곳을 돌아본 말. 1막 "서생" 말을 막 본문에 쓰기 위해 후렴은 이조년의 말로 함.
- **흠:** 측근에게 일을 맡기고 씨름(1막), 유학자를 미워함(1막), 담을 넘어 달아남(2막), 사냥·탄환 놀이·민가 철거·새 궁궐 노역·직세·백성과 신하의 아내를 함부로 대함(4막 context — 아이들용 표현만), 이조년의 두 번째 간언에도 바뀌지 않음(4막 context).
- **막:** 네 막 모두 딜레마형. 1막(기거주 — 기록을 가져온다/말없이 고친다 → "다 서생들"), 2막(이조년 — 사과/내쫓음 → 담을 넘음), 3막(조적 — 피한다/원나라에 고발 → 직접 나가 활), 4막(원나라 사신 — 끝까지 피함/먼저 알아봄 → 고룡보를 믿고 나감).
- **고리:** 충숙왕편 에필로그(황주 꾸중·'발피') = 1막 deep. 4막의 여섯 살 맏아들 → 충목왕편. 고룡보·기철 → 충목왕·공민왕편.
- **아동용:** 성폭력 기사는 "백성과 신하의 아내를 함부로 대했다"로만(3막·4막 context). 직세의 부녀 죽음은 게임에서 빼고 심화에만. 신궁에서 운 두 여인을 죽인 일 등은 쓰지 않음.
- **나이:** 그 해 − 1315. 1328 열셋, 1330 열다섯, 1332 열일곱, 1339 스물넷, 1340 스물다섯, 1343 스물여덟, 1344.1 스물아홉. "壽三十"은 세는나이. 맏아들 충목왕 1337생 → 1343 여섯.
