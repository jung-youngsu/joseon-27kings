### 설계 (2026-10-17)

- **축:** 아버지 문종 "後之復興王室者，其在爾乎！"(뒷날 왕실을 다시 일으킬 사람은 너로구나) + 성품 "雄毅果斷". 그 말을 지키려 기다리지 않고 직접 손댄 왕 — 돈·남경·별무반. 그 빠름이 조카의 자리를 받는 일로 시작했다.
- **흠:** 이자의 일당 처분("事不原情" — 1096 조정이 스스로 돌아봄)(1막), 즉위 당일 원신궁주·한산후 귀양·"躐等遷官者數百人"·요에는 '임시로 맡겼다'고 보고(2막), "民貧，不能興用"·남경 "事皆依日官所奏，不合禮制"(3막), 모두에게 지운 군역(4막).
- **막:** 네 막 모두 딜레마형. 1막 이자의(직접 궁으로/숨는다 → 재상에게 맡김), 2막 선위(끝까지 사양/곧장 받음 → 세 번 사양·그날 귀양), 3막 돈(그대로/만들어 두고 맡김 → 관리·군인에게 먼저 나눠 주고 가게), 4막 1104 패전(화친으로 끝/곧바로 재출병 → 별무반).
- **고리:** 프롤로그 곽상 ↔ 3막 곽상의 반대. 헌종편과 같은 1095년. 4막 맹세문 → 예종편 1막.
- **각색:** 프롤로그 narration(곽상이 문을 막음 — 권97 실제 기사, 1인칭 각색), 1·2·4막 narration·inner. 1막 dial은 이자의가 무리에게 한 말(권127).
- **나이:** 그 해 − 1054. 1094 마흔, 1095 마흔하나, 1102 마흔여덟, 1104 쉰, 1105 쉰하나. "壽五十二"는 세는나이. 헌종 1084 → 1095 열하나, 1097 열셋.
