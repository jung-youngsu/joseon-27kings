## 작업 메모

### 설계 (2026-10-17)

- **축:** 최승로 "天性剛毅，固執不移"(타고난 성품이 굳세어 한번 정하면 바꾸지 않았다). 형 혜종이 묻지 않는 동안 먼저 움직여 왕실을 지킨 그 굳셈이, 서경 천도에서는 백성의 원망 앞에 귀를 막는 고집이 되었다.
- **후렴:** 946.1 소나무 사이의 목소리 "爾堯，存恤細民，人君之要務" — 『고려사』가 정종 세가 첫머리에 실은 말. 정종의 부역과 견주는 장치.
- **흠:** 박술희를 의심해 귀양 → 왕규가 죽임(1막), 도참·강제 부역·개경 백성 이주("役夫聞而喜躍")(2막), 사리·7만 석·천둥에 놀라 병(2막 deep, 이제현).
- **막:** 세 막. 1막(형의 병석 — 아뢴다/피한다 → 왕식렴과 몰래), 2막(천도 — 멈춘다/개경에 둔다 → 고집), 3막(후계 — 아들/신하들이 고르게 → 친아우). 노란 점·먼저 묻기 없음.
- **고리:** 혜종편 1·2막과 같은 945년을 아우 쪽에서. 3막 → 광종편. 광군·거란 → 성종편(993).
- **각색:** 1막 narration(형의 병석), 2막 narration(원망 소리), 3막 narration·inner(왕식렴의 죽음 뒤 병석). 정종 자신의 말은 『고려사』에 남지 않음 ✘ — 대사 없이 inner만.
- **나이:** 그 해 − 923. 945 스물둘, 946 스물셋, 947 스물넷, 948 스물다섯, 949 스물여섯. "壽二十七"은 세는나이.
