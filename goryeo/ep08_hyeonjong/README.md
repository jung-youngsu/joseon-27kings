## 작업 메모

### 설계 (2026-10-17)

- **축:** 1009 최항에게 "朕少値閔凶，未聞義訓"(짐은 어려서 부모를 잃어 바른 가르침을 듣지 못했다). 태어난 날 어머니를, 네 살에 아버지를 잃고 숨어서 살아남은 소년이, 부모 대신 곁에 남은 사람의 말을 붙들고 나라를 지켰다(강감찬·지채문·김은부·언효와 효질). 그 성질이 흠도 됨 — 옳다 한 말을 접고, '운몽 놀이'라는 꾀도 받아들였다.
- **흠:** 아전 앞에서 못 들은 척, 지채문이 달아날까 의심(심화), "將軍言是也" 뒤의 "勢不獲已"(2막), 친조 약속을 '병'으로 핑계(3막), 장락궁 잔치에서 김훈·최질 등 19명(4막), 현화사 둔전 1,240결·후비 13명(에필로그), 박섬의 벼슬(심화).
- **막:** 다섯 막 모두 딜레마형. 1막 1010 남행(항복/개경 사수 → 강감찬의 말·남행+하공진), 2막 파산역(둘 다 데려감/둘 다 보냄 → 한 사람만), 3막 1012 친조(간다/성을 내준다 → 병 핑계·6성 거부), 4막 1014 김훈·최질(다 들어줌/즉시 맞섬 → 들어주고 1년 뒤 잔치), 5막 1019(다시 피함/성 밖 결전 → 청야·귀주).
- **후렴:** "\"짐은 어려서 부모를 잃어 — 바른 가르침을 듣지 못했다.\" / 열일곱 현종은 왕이 되자 스승을 청하며 이렇게 말했습니다."
- **고리:** 목종편(1009 강조) → 프롤로그. 1막 강감찬 → 5막 시 "當時不用姜公策". 2막 김은부의 딸 → 덕종·정종(靖宗)·문종. 3막 친조 거부·6성 → 덕종편 단교. 전주를 피함 → 태조편 훈요 8조(심화).
- **각색:** 프롤로그 narration(신혈사 구덩이·독 든 떡 — 권4·권88 기사, 1인칭은 각색), 2막 narration(피란길 — 권94 지채문전 장면들), 1막 dial(거란 임금의 화살 편지 — 권94 양규전, 양규에게 보낸 글을 왕에게 오는 압박으로 씀).
- **나이:** 그 해 − 992. 1006 열넷, 1009 열일곱, 1010 열여덟, 1011 열아홉, 1012 스물, 1014 스물둘, 1015 스물셋, 1018 스물여섯, 1019 스물일곱, 1031 서른아홉. "年十二"(1003)·"壽四十"은 세는나이. 강감찬은 1031 "年八十四"(세는나이)에서 948년생쯤 → 1018 "일흔 무렵"으로만.
