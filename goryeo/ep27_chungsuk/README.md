## 작업 메모

### 설계 (2026-10-17)

- **축:** 1325 교서 "中立觀變者，一國皆是 … 然迹其心，盖不得已，已皆寬宥"(가운데 서서 형세를 살핀 사람이 온 나라였다 … 그 마음을 따져 보면 어쩔 수 없었던 것이니 이미 다 용서했다). 아버지가 원나라에 남으려고 넘겨준 자리에서 '어린 임금' 소리를 듣던 사람이, 원나라에 붙들린 다섯 해 동안 온 나라가 눈치 보는 것을 보았다. 그래서 다 용서했지만 사람을 피했다("王性厭人 … 王之忌人如此").
- **흠:** 1317~1320 농사철 사냥·밤길 매질·성황당 방화(프롤로그 context), 아내가 맞았다고 호소한 낭장을 귀양(1막 deep), 연경에서 "王未能自明"(1막), 귀국 뒤 "不親政事"·왕고에게 왕위를 넘기려 함(3막), 원나라 사신을 피하고 측근 '삼청'에게 권세가 넘어감(4막), 아들의 어머니를 쫓고 아들의 사람들에게 보복(에필로그·심화), 목욕 사치(에필로그).
- **후렴:** "\"가운데 서서 형세를 살핀 사람이 — 온 나라였다.\" / 서른한 살 충숙왕은 다섯 해 만에 고려로 돌아와 이렇게 적었습니다."
- **막:** 네 막 모두 딜레마형. 1막(황제의 부름 — 버틴다/사신으로 해명 → 서둘러 감), 2막(연경 — 맞고발/양보 → 말로 신하를 꾸짖음, 지킨 것은 신하들), 3막(귀국 — 모두 벌함/말없이 덮음 → 공개 용서), 4막(매려 — 끝까지 피함/신하가 대신 → 직접 반박).
- **고리:** 충선왕편(넘겨준 자리) ← 프롤로그. 에필로그 황주 꾸중·'발피' → 충혜왕편 프롤로그·1막과 같은 장면.
- **각색:** 프롤로그·1~4막 narration과 inner(1인칭은 각색). 왕 자신의 말은 1313 교서, '작은 광대'(권124 전영보전), 1325 교서, 매려 앞의 답(1328)뿐 — 대사 대신 inner.
- **원 간섭기 왕호:** 프롤로그 context 첫 단락에서 풀이.
- **나이:** 그 해 − 1294. 1313 열아홉, 1321 스물일곱, 1322 스물여덟, 1325 서른하나, 1328 서른넷, 1330 서른여섯, 1339 마흔다섯. "壽四十六"은 세는나이.
