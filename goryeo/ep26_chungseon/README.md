### 설계 (2026-10-17)

- **축:** 1288 "汝輩使我癡暗，持弄掌上，如軟餠乎？"(너희는 나를 어리석게 만들어 손바닥 위의 무른 떡처럼 주무르려느냐) — 환관 원혁의 "殿下聰明大過，宜小寬容"에 맞선 말. 잘못이 다 보였기에 기다리지 않았고, 한꺼번에 고쳤고, 멀리서 고려를 다스렸다.
- **원 간섭기 왕호:** 프롤로그 context — '○종 → 충○' 시호를 충선왕 자신이 원에 청했다는 편찬자 설명("初國家 … 歷代之謚，皆稱爲宗 … 王表請 …").
- **흠:** "늙은 개"(1막), 무비·환관 처형과 40여 명 귀양(2막), 너무 빠른 개혁(3막), 아버지를 절로 옮기고 실록 185책을 원으로(4막), 원에 머문 전지 정치·각염법의 괴로움·세자 감 살해·"請待秋成"(5막), 1320 "遲留顧望"(에필로그), 측근 정치·숙비(심화).
- **막:** 다섯 막. 1막(배웅/어머니께 → 울며 직접 말함), 2막(아버지께/원 황실에 → 직접 처형), 3막(한 번만/미룸 → "臣不敢奉命"), 4막(끼지 않음/이긴 쪽을 따름 → 하이산 옹립), 5막(귀국/양위 → "王不納"). 모두 딜레마형.
- **고리:** 충렬왕편 3·4막·에필로그(사냥·무비·1298·1306·1307)를 아들의 자리에서. 에필로그 1321 편지 ↔ 충렬왕 1306 "我雖老，獨不畏死". 만권당 낙타 문답 ↔ 태조편. 둘째 아들 → 충숙왕편.
- **각색:** 1~5막 narration·inner, 2막 충렬왕 대사("且待服闋"), 5막 최유엄 대사(1309.4 전 "君位久不可虛 …"를 말로).
- **나이:** 그 해 − 1275. 1283 여덟, 1288 열셋, 1292 열일곱, 1297 스물둘, 1298 스물셋, 1307 서른둘, 1308 서른셋, 1309 서른넷, 1313 서른여덟, 1320 마흔다섯, 1321 마흔여섯, 1325 쉰. "時王年九歲"·"壽五十一"은 세는나이.
