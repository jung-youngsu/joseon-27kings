### 설계 (2026-10-17)

- **축:** 『고려사』에 이 왕 자신의 말은 하나도 없다 ✘. 남은 것은 남들이 그에 대해 한 말 — "年十一歲"(표문), "少主不堪保釐"(윤택 등), "王不能沮"(덕녕공주), "王怒濡，而未能斥"(최유), "臣非將 … 不敢奉命"(이권), "憂愁號泣"(희비). → "말이 남지 않은 아이 왕".
- **후렴:** 권89 덕녕공주 "忠定時，公主頗與政，王不能沮"(공주가 정치에 자못 끼어들었으나 왕은 막지 못했다).
- **노란 점(EDITORIAL §2 예외):** 사신 찬 "何能爲哉"(충목과 묶음), "王不能沮"로 근거.
  - 1막 원나라와 아이를 받든 어른들(지울 수 없음, mark = 원나라로 간다)
  - 2막 점이 없는 결재(`markNone`) — 왜구가 시작된 해, 아이가 몸소 한 일은 법석. 실제로 1350.3 장수 둘을 보냈으므로(누가 골랐는지 ✘) 선택지에 '장수를 보낸다'는 넣지 않고 '직접 군사를 이끈다'로 함.
  - 3막 새 왕의 사람들과 순군(지울 수 없음, mark = 한 사람만 데려간다)
- **deep의 '선택지 밖의 길'** = 받들려 감(1막), 몸소 연 법석(2막), 따라가려던 동무들과 어머니의 방문(3막).
- **흠:** 반대한 신하들의 귀양 — 『고려사』는 "忠定銜之"(원망했다)라 했으나 결정자 ✘(1막 deep), 최유·윤시우를 막지 못함(2막 context), 날짜 없는 '狂悖' 일화(에필로그 — 거리를 두고).
- **고리:** 충목왕편(형, 노란 점) → 1막. 왜구 → 공민왕·우왕편, 조선 태조편. 숙부 왕기 → 공민왕편. 충숙왕의 '托孤'(윤택) → 심화.
- **나이:** 세가에 태어난 해가 없다 ✘. 1348.12 이제현 표문 "王㫝 … 年十一歲"를 세는나이로 보고 1338년생으로 셈(같은 표문의 왕기 "年十九歲"는 1330년생과 세는나이로 맞음). 『고려사』 "壽十四"(1352)를 세는나이로 보면 1339년생이 되어 **한 살 어긋남** — 심화에 밝힘. 1348 열, 1349 열하나, 1350 열둘, 1351 열셋, 1352 열넷.
