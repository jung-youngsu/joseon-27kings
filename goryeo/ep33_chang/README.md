## 작업 메모

### 설계 (2026-10-17)

- **축:** 즉위 교서 "毋邇頑童，去聲色。絶遊畋 … 爲君不易，懋敬之哉"(아버지가 한 일을 하나하나 '하지 마라'로 뒤집은 글). 후렴은 창왕 자신의 말로 남은 거의 유일한 한마디 "遠人來貢，待之薄，則無乃不可乎？"(1389.8).
- **장치:** 노란 점(EDITORIAL §2 예외 — 기록의 거의 전부가 어른들이 아이 이름으로 한 일). 1막 간관·조준의 탄핵(지울 수 없음, 실제 작은 저항 = 술과 "功可相掩" → 생일 사면), 2막 `markNone`(유구국 사신 — 창왕이 스스로 고른 자리), 3막 어머니 근비와 도당(지울 수 없음, "昌將親朝" → "憫其年幼 … 寢其行").
- **흠:** 소목·후추를 궁에서 쓰겠다며 유백유의 간언을 듣지 않음(2막 deep). 그 밖의 '흠'은 실제 판단자가 누구인지 알 수 없어 억지로 늘리지 않음(최영 처형 "昌從之"은 2막 context 한 줄).
- **나이:** 그 해 − 1380(8월생). 1387 일곱, 1388.6 여덟(즉위 "年九歲"는 세는나이), 1389 아홉. 이색 1328생 → 1388 예순.
- **각색:** 프롤로그 narration(1387 금덩이 — 실제 기사, 아이 시점), 각 막 inner. 죽음 장면은 쓰지 않음(『고려사』에도 없음).
