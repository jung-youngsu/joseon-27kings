- **축:** 『고려사』 "執性剛斷"(성품이 굳세고 결단력이 있었다) + 1033 교서 "心切奉先思孝". 아버지가 이기고도 숙인 평화를 이어받은 열다섯 살이, 붙잡힌 사람을 돌려 달라 했다가 거절당하자 끊었다(소수 29명 쪽). 그러나 쳐들어가자는 장인의 말에는 멈추고, 아버지 신주를 모신 날 돌로 천 리를 쌓기 시작했다.

- **흠:** 장인의 딸을 맞은 날 장인의 주장을 표문으로(1막 deep), 큰일을 태묘 점에 맡김(2막), 단교의 값 — 정주 침공·사신들은 끝내 못 돌아옴(3막·에필로그), 이복누이와 혼인(에필로그·심화). 기록이 적어 흠도 적음 — 지어내지 않음.
