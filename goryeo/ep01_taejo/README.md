## 작업 메모

### 설계 (2026-10-17)

- **축:** 훈요 7조 "人君得臣民之心爲甚難"(임금이 신하와 백성의 마음을 얻기란 매우 어렵다). 913 "務得衆心"부터 918 "重幣卑辭", 931 "如見父母", 935 "朕心雖愧", 스물아홉 번의 혼인까지 — 마음을 얻는 것으로 나라를 묶은 사람. 그것을 누구보다 잘한 사람이 "매우 어렵다"고 적었다.
- **흠:** 거짓 자복으로 자기를 먼저 살림(1막), 즉위 한 해의 처형들 — 낮춘 말 뒤의 칼(2막), 기다림의 값 — 경애왕의 죽음·공산에서 죽은 신숭겸·김락(3막), 혼인 정치가 남긴 스물다섯 왕자와 외가 호족(4막), 만부교 낙타·훈요 8조 지역 차별(에필로그), 오어곡성 항복 장수의 처자 처형(심화).
- **후렴:** "\"임금이 신하와 백성의 마음을 얻기란 — 매우 어렵다.\" / 예순여섯 왕건은 세상을 떠나기 전, 뒷날의 왕들에게 이렇게 적어 남겼습니다."
- **장치:** 먼저 묻기·노란 점 없음. 네 막 모두 딜레마형(왕건의 길은 선택지 밖: 거짓 자복 / 낮춘 말+칼 / 성벽을 지키며 기다림 / 받되 높이 앉히고 혼인).
- **고리:** 4막 deep 끝 "그 마음들이 서로 부딪치기 시작합니다" → 고려 EP02 혜종(왕규). 942 거란 → 성종·현종편. 조선 EP01 태조편(추대된 무장)과 견주기 — 심화 '이어서 보기'.
- **각색:** 프롤로그 narration(909 나주 — "師克在和" 실제 말, 장면은 각색), 1막 game의 궁예 대사 "……보인다"(실록의 "仰天良久"를 말로 — 장면 각색), 2막 narration(갑옷 — 권88 신혜왕후전).
- **나이:** 시리즈 기준(그 해 − 877). 896 열아홉, 909 서른둘, 914 서른일곱, 918 마흔하나, 926 마흔아홉, 935 쉰여덟, 943 예순여섯. 『고려사』 "時太祖年二十"·"壽六十七"은 세는나이. 견훤은 "十年之長"(열 살 위)만 씀.

- 장화왕후 오씨의 '돗자리' 설화 — 쓰지 않음(혜종편 자황포만).
- 왕창근 거울 참문 — 심화에 '덧붙였을 수 있는 이야기'로만.
- 훈요 위작설 — 학설로만(이병도 등 ≈), 반론과 함께.
