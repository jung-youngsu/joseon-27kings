## 작업 메모

### 설계 (2026-10-17)

- **축:** 991 사직 교 "朕纘承以來，凡所施爲，必依禮典"(짐이 왕위를 이은 뒤로 하는 일은 모두 예법 책을 따랐다). 이를 갈 무렵 어머니, 아홉 살에 아버지를 잃고 할머니 품에서 자란 사람이, 왕이 되는 법을 책과 신하의 글에서 배웠다(시리즈의 '물려받은 게 없어서 이해되는' 경우 — 조선 선조편과 짝).
- **흠:** 말하라던 왕이 정우현을 벌하려 함(1막), 987 풀려난 노비를 다시 천인으로(2막), 숙부를 끝내 풀어 주지 않음(3막), 993 경고 무시·할지론에 기욺·쌀을 대동강에·팔관회 폐지 "樂慕華風，國人不喜"(4막), 즉위 초 공덕재(심화), 984 압록강 축성 실패(심화).
- **막:** 다섯 막. 1막 각상봉사(대신에게/가까운 몇 사람 → 5품 이상 모두), 2막 12목(호족에게/그때그때 사신 → 관리 상주), 3막 안종(무겁게 벌/덮음 → 귀양+아이를 아버지에게), 4막 거란(할지/항복 → "誰能往契丹營" 서희를 보냄 — 성종이 실제로 할지에 기울었음을 deep 첫 줄에 밝힘), 5막 사면(크게/가볍게 → 거절).
- **고리:** 경종편 3막(손을 잡고) → 프롤로그. 광종편(노비안검·서필·북쪽 두 성) → 2·4막. 3막 아이 → 현종편. 5막 개령군 당부 → 목종편.
- **각색:** 각 막 narration·inner. 4막 dial "어전 회의의 신하들"은 서희전 "或言 … 或言 …"을 옮긴 말, 서희 대사는 서희전 원문을 줄인 말. 5막 왕융 대사는 "謂頒赦"를 말로.
- **나이:** 그 해 − 960. 969 아홉, 981 스물하나, 982 스물둘, 983 스물셋, 991 서른하나, 992 서른둘, 993 서른셋, 997 서른일곱. 최승로 927 → 982 쉰다섯. 서희 942 → 993 쉰하나. "壽三十八"은 세는나이.
