## 작업 메모

### 설계 (2026-10-17)

- **축:** 1259 송길대왕에게 "大王之言，其可信乎？"(대왕의 말을 믿을 수 있겠습니까). 군대가 없던 왕이 말과 약속으로 시간을 벌고, 먼저 찾아가는 발걸음(1259 쿠빌라이)과 사돈의 이름(1270 청혼)으로 무신의 백 년을 끝냈다.
- **흠:** 약속을 어김 "卿先後食言，多矣"(1267)·"敷奏不實可乎"(1271), 칼을 칼로 — 임연을 "眞忠臣"이라 불렀다가 폐위됨(2막), 행성 앞에서 진실을 감추고 이장용을 데려가지 않음(3막), 원군을 불러 권신을 없앤 값 — 동녕부·강화 약탈·삼별초(3·4막), 궁녀·맏아들 의심(심화), 사신 찬 "溺於宴安".
- **막:** 네 막 모두 딜레마형. 1막(북쪽 아릭부케/연경에서 관망 → 남쪽 쿠빌라이), 2막(김준 뜻대로 싸움/내버려 둠 → 임연과 몰래 제거), 3막(군대만/아무것도 → 혼인+군대), 4막(이장용의 여름·겨울 안/삼별초를 왕의 군대로 → 전원 출륙·삼별초 해산).
- **고리:** 고종편 에필로그(아들은 길 위에) → 1막. 3막 혼인 → 충렬왕편. 4막 삼별초의 기원 → 고종편(야별초).
- **각색:** 1막 narration(큰물 — 실제 "太子不聽遂行"), 2·3·4막 narration·inner. 원종이 쿠빌라이를 고른 까닭 ✘ — deep에서 "…였을 것입니다".
- **나이:** 그 해 − 1219. 1231 열둘, 1235 열여섯, 1259 마흔, 1260 마흔하나, 1268 마흔아홉, 1269 쉰, 1270 쉰하나, 1271 쉰둘, 1274 쉰다섯. "壽五十六"은 세는나이.
- **이름 표기:** 1271.12 국호 '대원' 전은 '몽골', 뒤는 '원'.
