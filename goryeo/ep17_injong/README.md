## 작업 메모

### 설계 (2026-10-17)

- **축:** 1132.11 제서 "親親之恩，天性自然，每一念來，痛心切骨"(혈육을 아끼는 정은 타고난 것이라 생각날 때마다 뼈가 아프다) + 김신부 "一於慈愛，優游不斷". 어머니를 아홉 살에 잃고 외가에서 자란 왕이 외할아버지도, 척준경도, 묘청도 모질게 끊지 못했다. 그 마음이 금과의 전쟁을 피하고 서경에서 "愼勿多殺"이 되었다.
- **흠:** 뜻만 비쳐 2월 거사를 부르고 산호정에서 선위 글(1막), 척준경을 쓰고 버림(2막), 묘청을 믿지도 끊지도 못함·대화궁 공사 "民甚怨咨"(3막), 항복한 사신 하옥 → 재반란·정지상 선참후주를 막지 못함·'西京逆賊' 자자(4막), 병중 무당 말에 벽골지 둑을 터뜨림(에필로그).
- **막:** 네 막 모두 딜레마형. 1막 이자겸(기다림/다 맡김 → 뜻만 비침·산호정), 2막 척준경(믿지 않음/곧바로 명함 → "反狀未著"를 기다림), 3막 묘청(칭제·금 정벌/처형 → 대화궁은 짓되 칭제는 거절·"朕不西行"), 4막 1135(단숨에/몸소 서경에 → 김부식에게 "愼勿多殺"·자책 조서).
- **고리:** 예종편 에필로그(이자겸) → 1막. 정습명·맏아들 걱정 → 의종편(심화).
- **각색:** 1·2·3·4막 narration·inner. 2막 dial "척준경이 보낸 말"은 권127 "願自効"를 말로.
- **나이:** 그 해 − 1109. 1122 열셋, 1126 열일곱, 1132 스물셋, 1134 스물다섯, 1135 스물여섯, 1145 서른여섯, 1146 서른일곱. "壽三十八"은 세는나이. 출생 일진은 권13 乙亥·권15 己亥로 엇갈림(심화).
