## 작업 메모

### 설계 (2026-10-17)

- **축:** 명종의 시 "短懷拙智一難斷"(짧은 생각 서툰 지혜로는 하나도 끊어 내기 어렵다) + 1194 "賊亦民也，奚多殺爲？". 형을 두려워하며 자란 동생("上聞之，必害我矣")이 칼을 든 무신들 손에 왕이 되어, 아무도 다치게 하지 않으려다 아무것도 끊어 내지 못했다.
- **후렴:** 위의 시 구절.
- **장치:** 예종편식 **지울 수 있는 노란 점**(erasable) — 1막(병마사), 3막(조정), 4막(관청). 명종은 고를 수 있었으나 늘 무신·관청의 점이 찍혀 왔다("凡軍國機務，皆牽制武臣"). 1막은 지웠다가 신하들이 다시 찍음(충순현 → 삭제), 3·4막은 그대로 둠(1194 "有司固請從之"). 2막(경대승)은 점이 없는 일반 선택.
- **흠:** 경대승 도방을 혹독하게 고문(3막 context), 형을 죽인 이의민을 재상으로(3막), 하비와 "得賂幾何"(3막 deep), 간관을 가두고 아우를 감쌈(심화·3막 context), "賊亦民也"와 같은 무렵 처자 350여 명 노비(4막).
- **고리:** 의종편 에필로그(금에 보낸 '아우에게 물려준다'는 글) → 이 편 에필로그에서 1197 똑같은 글. 아우 평량공 → 신종편. 태자 강종 → 강종편.
- **각색:** 프롤로그·1~4막 narration·inner. 1막 병마사 대사는 "士卒多亡，請募僧以濟師"를 말로, 4막 관청 대사는 "崔仁，嘗自絀退 …"를 말로.
- **나이:** 그 해 − 1131. 1170 서른아홉, 1176 마흔다섯, 1179 마흔여덟, 1183 쉰둘, 1185 쉰넷, 1194 예순셋, 1197 예순여섯, 1202 일흔하나. "壽七十二"(명종 자신의 말)는 세는나이.
