## 작업 메모

### 설계 (2026-10-17)

- **축:** 김치양전 "穆宗常欲黜之，恐傷母志，不敢也"(늘 내치려 했으나 어머니 마음이 다칠까 두려워 하지 못했다). 후렴은 목종 자신의 1003 교서 "余幼失義方，長無師訓"(어려서 바른 가르침을 잃었고 자라서도 스승의 가르침이 없었다). 한 살에 아버지를 잃고 당숙에게 길러진 사람에게 어머니는 하나뿐인 집이었다.
- **흠:** 평주 "酣飮不行"(1막 deep), 김치양을 둠·유행간을 지나치게 아낌(2막), 후계를 늦게 정함 "是吾過也"(3막), 강조를 불러 칼을 빌림·마지막에 유행간을 넘김(4막), 놀이용 토목(1막 context 교서).
- **막:** 네 막. 1막 쇠돈(밀어붙임/아예 없앰 → 가게에서만 돈 — 방법형), 2막 김치양(귀양/어머니를 따로 → 아무것도 못 함 "恐傷母志"), 3막 후계(기다림/어머니의 아이 → 대량원군, 몸소 먹을 갊), 4막 궁 지키기(궁 안 군사/강조를 국경에 → 강조를 부름).
- **고리:** 성종편 3막 아이·5막 개령군 당부 → 프롤로그·2막. 에필로그 → 현종편(강조 문책의 거란 침입).
- **각색:** 각 막 narration·inner. 1막 한언공 대사는 권79 상소를 줄인 말, 3막 채충순 대사는 "勢急矣，宜早圖之".
- **아이들용 표현:** 유행간의 "龍陽之寵"은 쓰지 않고 '지나치게 아끼던 신하'로. 태후와 김치양은 '사이에서 아들을 낳았다'까지.
- **나이:** 그 해 − 980. 981 한 살, 997 열일곱, 1002 스물둘, 1003 스물셋, 1007 스물일곱, 1009 스물아홉. "壽三十"·"年己十八"은 세는나이.
