## 작업 메모

### 보강 — 5막 「어느 내 사람을 지키는가」 (2026-10-16)

- 게임이 위화도·정몽주(건국 전)에서 끝나 왕으로서의 선택이 없었다. 1392.8 세자 책봉을 고르는 5막을 더했다. 선택지: 나이(한씨의 맏아들 쪽) · 공(방원) · 강씨의 뜻. deep 끝에 「그는 왜 그랬을까」 — 내 사람을 지키는 마음이 어느 내 사람을 지킬지 골라야 했다.
- 에필로그에 한양 천도(1394) 한 줄 — 0막 쌍성의 "땅을 바꾸어 사람을 바꾼다"와 잇는다.
- 근거(위키문헌 『太祖實錄』): 元年 8.20 「立幼孼芳碩爲王世子。初功臣裵克廉、趙浚、鄭道傳請建世子，欲以年以功爲請，上重康氏意在芳蕃。芳蕃狂率無狀，功臣等難之… 克廉曰：『季子爲可。』上遂決意立之。」 · 三年 10.25 「遷都漢陽」
- 「幼孼」(어린 얼자)은 태종 때 편찬된 실록의 말이다. deep에서 "누가 쓰느냐에 따라 기록의 말이 달라진다"로 짚었다.

### 쉬운 말 다듬기 (2026-10-16)
- 바꾼 말 (전 → 후), 처음 나올 때 괄호 풀이를 단 말
  - 토박이 호족 → 대대로 뿌리내린 호족(그 지방에서 땅과 사람을 거느린 힘 있는 집안)
  - 핍박·멸시·궁핍 → 괴롭힘·업신여김·가난 / 부역 → 부역(나라가 백성을 불러다 대가 없이 시키는 일)
  - 황실 → 황제 집안 / 반기를 들었습니다 → 맞서 들고일어났습니다
  - 밀사·명분·쌍성총관부 → 괄호 풀이(몰래 보낸 심부름꾼 / 떳떳하게 내세울 이유 / 원나라가 이 땅을 다스리려고 세운 관청)
  - 홍건적 → 붉은 수건 이름 풀이 한 줄, 요동(지금의 중국 동북쪽 땅), 선봉(맨 앞에서 쳐들어오는 부대)
  - 정예·약탈 → 날랜 군대·곡식과 재물을 빼앗으며 / 황산대첩(황산에서 거둔 큰 승리) / 왜구(바다를 건너와 노략질하던 일본 해적)
  - 묵살 → 들어 주지 않았다 / 격노 → 크게 노했다 / 거역 → 맞서는 / 출정에 앞서 → 싸우러 떠나기 전에
  - 아교·역병·범람·당도 → 아교(짐승 가죽으로 만든 풀)·전염병·넘쳐흐르고·도착 / 위화도(압록강 가운데의 섬)
  - 선택지 "회군한다" → "군대를 돌린다" / 역적(나라를 배신한 죄인)
  - 낙마 사고 → 말에서 떨어져 / 귀양(벌로 먼 곳에 보내 지내게 하는 것) / 하여가·단심가 → 시조 「하여가」·「단심가」, 단심가 뜻풀이 한 줄
  - 선죽교에서 정몽주를 쳤습니다 → 개경의 돌다리 선죽교에서 정몽주를 쳐 죽였습니다 (첫 등장만 직설)
  - 분개했다고 … 실상은 → 몹시 화를 냈다고 … 진짜 속마음은
  - 공신·세자·실록·도읍·이복동생 → 처음 나올 때 괄호 풀이 / 경솔 → 성급하고 가볍다
