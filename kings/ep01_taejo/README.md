### 보강 — 5막 「어느 내 사람을 지키는가」 (2026-10-16)

- 게임이 위화도·정몽주(건국 전)에서 끝나 왕으로서의 선택이 없었다. 1392.8 세자 책봉을 고르는 5막을 더했다. 선택지: 나이(한씨의 맏아들 쪽) · 공(방원) · 강씨의 뜻. deep 끝에 「그는 왜 그랬을까」 — 내 사람을 지키는 마음이 어느 내 사람을 지킬지 골라야 했다.
- 에필로그에 한양 천도(1394) 한 줄 — 0막 쌍성의 "땅을 바꾸어 사람을 바꾼다"와 잇는다.
- 근거(위키문헌 『太祖實錄』): 元年 8.20 「立幼孼芳碩爲王世子。初功臣裵克廉、趙浚、鄭道傳請建世子，欲以年以功爲請，上重康氏意在芳蕃。芳蕃狂率無狀，功臣等難之… 克廉曰：『季子爲可。』上遂決意立之。」 · 三年 10.25 「遷都漢陽」
- 「幼孼」(어린 얼자)은 태종 때 편찬된 실록의 말이다. deep에서 "누가 쓰느냐에 따라 기록의 말이 달라진다"로 짚었다.

### 쉬운 말 다듬기 (2026-10-16)
- 바꾼 말 (전 → 후), 처음 나올 때 괄호 풀이를 단 말
  - 토박이 호족 → 대대로 뿌리내린 호족(그 지방에서 땅과 사람을 거느린 힘 있는 집안)
  - 핍박·멸시·궁핍 → 괴롭힘·업신여김·가난 / 부역 → 부역(나라가 백성을 불러다 대가 없이 시키는 일)
  - 황실 → 황제 집안 / 반기를 들었습니다 → 맞서 들고일어났습니다
  - 밀사·명분·쌍성총관부 → 괄호 풀이(몰래 보낸 심부름꾼 / 떳떳하게 내세울 이유 / 원나라가 이 땅을 다스리려고 세운 관청)
  - 홍건적 → 붉은 수건 이름 풀이 한 줄, 요동(지금의 중국 동북쪽 땅), 선봉(맨 앞에서 쳐들어오는 부대)
  - 정예·약탈 → 날랜 군대·곡식과 재물을 빼앗으며 / 황산대첩(황산에서 거둔 큰 승리) / 왜구(바다를 건너와 노략질하던 일본 해적)
  - 묵살 → 들어 주지 않았다 / 격노 → 크게 노했다 / 거역 → 맞서는 / 출정에 앞서 → 싸우러 떠나기 전에
  - 아교·역병·범람·당도 → 아교(짐승 가죽으로 만든 풀)·전염병·넘쳐흐르고·도착 / 위화도(압록강 가운데의 섬)
  - 선택지 "회군한다" → "군대를 돌린다" / 역적(나라를 배신한 죄인)
  - 낙마 사고 → 말에서 떨어져 / 귀양(벌로 먼 곳에 보내 지내게 하는 것) / 하여가·단심가 → 시조 「하여가」·「단심가」, 단심가 뜻풀이 한 줄
  - 선죽교에서 정몽주를 쳤습니다 → 개경의 돌다리 선죽교에서 정몽주를 쳐 죽였습니다 (첫 등장만 직설)
  - 분개했다고 … 실상은 → 몹시 화를 냈다고 … 진짜 속마음은
  - 공신·세자·실록·도읍·이복동생 → 처음 나올 때 괄호 풀이 / 경솔 → 성급하고 가볍다

### 문장·문맥 다듬기 (2026-10-16)
- 0막 context "심하게 괴롭힘을 당하지는 않았습니다" → 주어 "이성계의 집안은"을 밝힘 / "아버지의 동료들" → "아버지 이자춘의 동료들"
- 0막 "기회는 오지 않았을 것입니다" → "차별에서 벗어날 기회는…" (feedback·deep 둘 다)
- 0막 deep "명분이 있었습니다" 뒤에 무슨 명분인지 한 줄 — 고려 왕의 뜻을 받고 움직였으니 반란이 아니라 나라의 일
- 1·2막 deep 첫 줄 "싸웠다면 —" → "무작정 싸웠다면" / "혼자 싸웠다면" (feedback은 "이성계도 싸웠다"인데 deep이 싸움을 나쁘게 말하는 것처럼 읽히던 것)
- 2막 deep "얼굴을 가린 투구만이 빈틈" → "빈틈은 얼굴 하나뿐인데, 그마저 투구가 가리고 있었다"
- 3막 narration "이성계는 사불가론을 올렸다" → "나는 이 싸움을 해서는 안 되는 네 가지 까닭(사불가론)을 올렸다" (1인칭 + context보다 먼저 나오는 낱말 풀이)
- 3막 전령 "최영 장군의 명" → "전하의 뜻을 받든 최영 장군의 명" (선택지 "이 왕명"과 이어지게)
- 3막 ② feedback → "아무 준비 없이 그냥 거부했다면 — 명분이 없었을 것" (가정법; 실제로 군대를 돌린 것과 헷갈리지 않게)
- 4막 narration "이성계가 말에서 떨어졌다" → "내가 말에서 떨어졌다", "이용했다" → "노렸다"
- 4막 신하 "전하. …쳤습니다" → "대감. …쳐 죽였습니다" (1392년 4월은 아직 왕이 아님)
- 4막 ② feedback·deep "정몽주는 쓰러졌습니다. 사라진 것이 아니었습니다" → "힘으로 이기면 적이 쓰러질 뿐 사라지지 않는다. 정몽주는 쓰러졌지만 칼로 일을 끝내는 방식은 남았다" (0막 quote와 6년 뒤를 잇는 다리)
- 4막 deep "밖을 향한 방법이 안을 향할 때는 달랐습니다" → "그 방법은 밖의 적에게만 통했다. 내 사람이 잘못했을 때는 달랐다"
- 5막 narration "내 곁에는 강씨가 있다" → "아내 강씨" / deep "그 칼이 정몽주를 친 칼" → "정몽주를 친 손에 다음 왕의 자리를 쥐여 주는 일" / "4년 뒤 강씨가 … 2년 뒤" → "1396년 강씨가 세상을 떠나고, 2년 뒤"
- 에필로그 "또 명분을 만들었습니다" 앞에 즉위교서 한 줄("나라의 제도는 고려의 것을 그대로 따른다")
- 에필로그 "쌍성에서 배운 대로 — 땅을 바꾸어 사람을 바꾼 것" → "땅을 옮겨 — 그 땅에 뿌리내린 높은 집안들의 힘을 떼어 놓은 것" (0막에 그 배움이 나오지 않아 잇기 어려웠음) / "안은 달랐습니다" → "집안의 일은 달랐습니다"

### 사실 확인 (2026-10-16)

- 2막 deep 황산대첩: 「이지란이 투구를 맞히고 이성계가 쏘았다」 → 이성계가 투구 꼭지를 두 번 쏘아 투구를 떨어뜨리고 이지란이 쏘아 죽였다. 태조실록 총서 「太祖曰：我射兜鍪頂子令脫，汝便射之 … 兜鍪遂落，豆蘭便射殺之」. 처음에 사로잡으라 한 대목(「太祖惜其勇銳，命豆蘭生擒之」)도 넣음. 퀴즈 9·11번 같이 고침(「황금 투구」는 근거 없음 → 「護項面甲，無隙可射」).
- 1막 deep 「이지란은 이 전투(홍건적)에서 이성계의 사람이 됐다 / 어깨에 화살 / 30년」 → 근거 없음. 총서의 홍건적 기사(1362)에 이지란이 나오지 않음. 태종실록 2년 4월 9일 졸기 「早從太上王征戰獻捷」만 옮김. 퀴즈 6번 「1361년 홍건적 토벌부터」도 고침.
- 에필로그 「쌍성에서 배운 대로」: 0막에 「땅을 바꾸어 사람을 바꾼다」는 배움이 없음 → 지운 채로 둠. (study.md 인과표의 「0막 쌍성에서 배운 수」 줄은 아직 남아 있음)

### 업적 막 보강 · 『고려사』와 맞추기 (2026-10-17)

- 사용자 요청: "업적 한두 개씩은 꼭 들어가게 — 태조의 과전법은 (권문)세족의 힘을 누르기 위함이었다처럼." 막을 둘 더하고, 그 뒤 막 번호를 하나씩 미룸(정몽주 4→5막, 세자 5→6막).
- **새 4막 · 1389 「땅 문서를 불태우다」** — 과전법. 선택지: 이색의 말대로 지나친 땅만 돌려주게 함 / 미룸. 실제: 조준의 의논을 따름 → 1390.9 공·사 전적을 저잣거리에서 불태움 → 1391.5 과전법(경기, 18과). 동기 문장: "과전법은 권문세족이 쥔 땅을 거두어 나라 살림과 새로 나선 관리·군사에게 돌려, 고려의 큰 집안들이 더는 힘을 쓰지 못하게 하려는 것이었습니다." (사용자가 쓴 '호족'은 고려 말이므로 '권문세족'으로.)
  - 근거: 『고려사』 권118 조준전 "我太祖與浚、鄭道傳，議革私田 … 侍中李穡以爲不可輕改舊法 … 鄭夢周依違兩閒 … 議者五十三人，欲革者十八九，其不欲者皆巨室子弟也。太祖卒用浚議革之" / 권78 식화지 1388.7 조준 "夫仁政，必自經界始 … 跨州包郡，山川爲標 … 一畝之主，過於五六，一年之租，收至八九" / 같은 해 간관 이행 "國田之租，半入於無用之人，軍士飢色"(조준이 아니라 이행의 글 — 대사로 나눔) / 공양왕 2년(1390).9 "焚公私田籍于市街，火數日不滅。王嘆息流涕曰：祖宗私田之法，至于寡人之身，而遽革，惜哉。" / 3년(1391).5 "請定給科田法 … 自一品，至九品散職，分爲十八科" ✔
- **새 7막 · 1394 「왕도가 될 만하다」** — 한양 천도. 먼저 묻기: 정도전("치란은 사람에 달렸다 … 민력을 쉬게 하며 때를 기다리라") · 하윤(무악) · 성석린(부소, 두어 해 뒤). 선택지: 개경에 머묾 / 무악. 실제: 이튿날 남경 옛 궁궐터 "松京亦豈無不足處乎？今觀此地形勢，可爲王都。況漕運通道里均" → 한양으로 정함 → 10.25 천도. 동기 문장: "한양 천도는 고려의 큰 집안들이 오백 년 동안 뿌리내린 개경을 떠나, 새 나라를 새 땅에서 시작하려는 것이었습니다." 실록이 든 까닭(도참·조운·도리균)과 학자들의 풀이(개경 세력에서 벗어남)를 나누어 밝힘.
