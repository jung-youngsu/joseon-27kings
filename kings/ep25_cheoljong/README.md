## 작업 메모

### 설계 (2026-10-17)

- **축:** 1850.5.12 어제 10조 "非書之爲難，行之惟難"(쓰기가 어려운 게 아니라 행하기가 어렵다). 3대째 죄인 집안에서 자라 공부가 끊긴 청년이, 처음 가족의 정을 준 순원왕후의 뜻을 따르는 것을 도리로 삼고, 업신여김을 받아 본 사람이라 남을 쉽게 벌하지 못한 왕. 무엇이 잘못인지 알고 적어 두었지만(병풍·침실 벽·이정 절목) 맞서서 행하지는 못했다.
- **흠:** 대비의 이름 뒤에 숨음("그건 내가 모르겠다", 2막), 탐관오리를 알고도 벌하지 않음 → 진주(3막), 과거 부정 삭과를 한 해 반 만에 되돌림(3막 deep), 외척 인사, 개혁에 반대한 정원용을 영의정에 앉히고 삼정을 옛 규정으로(4막), 형 복권을 아홉 해 미룸(에필로그).
- **후렴:** "\"쓰기가 어려운 게 아니라, 행하기가 어렵다.\" / 열아홉 철종은 손수 쓴 열 가지 다짐을 보이며 이렇게 말했습니다."
- **장치:** 4막 먼저 묻기(정원용·김흥근·김좌근 — 모두 1862.윤8.11 실제 발언). 노란 점은 쓰지 않음.
- **고리:** 프롤로그 ↔ 헌종편 2막(1844 역모). 1막 context ↔ 헌종편 에필로그("강화에 사는 원범뿐"). 에필로그 → 고종편(대비가 다시 왕을 고름, 봉영은 김좌근). 박규수 → 고종편.
- **각색:** 프롤로그 narration(배 위 "괜찮습니다. 곧 닿습니다." — 행록 "慰護家眷，少不驚怖"를 장면으로), 1막 narration(강화 집 마당에 엎드린 사람들 — 실록에 봉영 장면 없음, context에 밝힘), 1막 deep("곧바로 입을 열지 못했던 것 같습니다" — 권돈인의 "必爲賜答" 재촉에서 짐작, 짐작임을 밝힘).
- **나이:** 시리즈 기준(그 해 − 1831). 1841 열, 1844 열셋, 1849 열여덟, 1850 열아홉, 1851 스물, 1859 스물여덟, 1862 서른하나, 1863 서른둘. 순원왕후 1789 → 1849 예순. 정원용 1783 → 1862 일흔아홉("여든을 앞두고"). 실록 "十九歲"·"春秋三十三"은 세는나이.

### 확인하지 못한 것 / 쓰지 않은 것

- 강화에서 농사·나무: 실록·부록 없음 — 에필로그·심화에 "실록에 없다"고 밝힘. 헌종편 에필로그의 "농사짓던"도 "살던"으로 고침.
- 형 이원경의 죽음: 헌종실록 1844년에 이름 없음 — "전합니다"로 씀.
- 강화 유수의 이름·날짜: 실록 없음 — 이름을 짓지 않음.
- 이정청 폐지 날짜, 되돌린 까닭에 대한 왕의 말: 못 찾음. 10.29 원문은 "二政"(사이트 제목은 "삼정") — 게임은 "삼정을 옛 규정대로".
- 1857 제문의 대작 여부: 단정하지 않음 — 에필로그에 "신하가 대신 지었을 수도".
- 강화 처녀 이야기·독살설·주색설: 쓰지 않음(심화에 근거 없다고만).
