## 작업 메모

### 설계 (2026-10-17)

- **축:** 지문 "王有其志矣，而末究其施"(뜻은 있었으나 끝내 펼치지 못했다). 아버지 얼굴을 기억하지 못한 아이가 할머니의 발 뒤에서 자라 늘 "여쭙고" 따르다가, 이제 막 스스로 서려던 스물둘에 멈춘 왕. 그가 스스로 한 것(총위영·조병현 보전)은 그가 죽자 곧 사라졌다.
- **흠:** 김대건 처형(3막 — 자기 생각인 "청에 알리기"를 영의정 반대에 거두고 "약함을 보이지 않으려" 직접 명함), 바른말 한 정언 윤행복 파직(4막), 외가를 감쌈, 궁궐 공사·서화 수집(에필로그). 폭군도 무능한 왕도 아닌, 겁날 때 약해 보이지 않으려 한 열아홉.
- **후렴:** "\"뜻은 있었으나, 끝내 펼치지 못했다.\" / 헌종이 세상을 떠난 뒤, 신하는 이렇게 적었습니다."
- **장치:** 3막(권돈인·김대건)·4막(윤행복·이목연) 먼저 묻기. 김대건의 says는 실록 1846.7.25 "自云『能通洋外諸蕃話，故以神父而爲各國通事』". 노란 점은 쓰지 않음.
- **고리:** 1막 deep ↔ 순조편 2막(1809 모든 고을에 폐단 적어 올리기). 4막 deep "대대로 섬긴 신하"(1847.10.17 "全保世臣") ↔ 순조편 4막(1830.9.28 "保世臣"). 3막 1846 청에 알리자 → 1847.8.11 실제로 알림. 에필로그 → 철종편(원범, 총위영 되돌림, 조병현 사사, "대왕대비께 여쭙겠다").
- **각색:** 프롤로그 narration(흰옷, "나도 고운 옷은 입기 싫어" — 어머니 언교 "吾亦不欲着華服"), 3막 inner("일곱 해 전이라는 것까지 어떻게 알았을까" — 7.15 헌종 발언을 속마음으로 당김).
- **나이:** 시리즈 기준(그 해 − 1827). 1830 셋, 1834 일곱, 1837 열, 1839 열둘, 1840 열셋, 1843 열여섯, 1844 열일곱, 1845 열여덟, 1846 열아홉, 1847 스물, 1849 스물둘. 효명세자 1809 → 1827 열여덟, 1830 스물하나. 김대건 1821 → 1836 열다섯, 1846 스물다섯. 철종 1831 → 1849 열여덟(실록 대왕대비 "十九歲"는 세는나이 — 게임·퀴즈는 열여덟, 심화는 실록 말 "열아홉"에 세는나이라고 덧붙임).
