### 문장·문맥 다듬기 (2026-10-16)

`scenes.json`만 손봄(22곳). 사실·순서·먼저 묻기 구조는 그대로.
- 1막 context (사용자 지적): 「황윤길의 말을 편드는 사람은 힘을 잃은 서인 편을 들어 백성의 마음을 흔든다는 말을 들었습니다」 → 「"전쟁이 난다"는 황윤길의 말에 맞장구치면 이런 손가락질을 받았습니다. "힘을 잃은 서인 편을 드는구나. 괜히 백성들만 겁주는구나."」
- 1막 game (사용자 지적): 왕의 물음 뒤에 대답이 없이 전쟁 대비로 건너뛰던 것 → "두 사신이 왕 앞에 나란히 섰다 … 두 사람의 대답은 정반대였다" + inner "한 사람은 전쟁이 난다 하고, 한 사람은 걱정할 것 없다 한다. 전쟁이 난다고 믿으면…"
- 프롤로그 context: 유모 이야기를 두 문장으로
- 1막: "여덟 해째인 1575년" → "여덟 해 뒤인 1575년" / deep 첫 두 줄("그가 다 하지 않은 일", "다 고른 길은 아니었다")을 뜻이 보이게 / 신립·이일 "활과 창이 몇 개인지만" / 김성일을 경상도로 보낸 문장을 "성 쌓기에도 반대 → 왕은 옳지 않다고 여김 → 보냄" 순서로 / "바다 건너 일본의 칼"
- 2막 deep: "그리고 그날 밤 군사들이 흩어졌다" → "그러나 그날 밤, …군사들마저" / "자리를 보증해 준 것" → "그가 왕이라는 것을 뒷받침해 준 것"
- 3막: 윤두수 "얼굴빛을 잃었사옵니다" → "놀라 얼굴빛이 하얗게 질렸사옵니다" / inner "전쟁이 시작되던 밤" → "전쟁이 나자"(떠난 것은 4.30) / 선택지 "글은 내보내되" → "글은 그대로 두고"(글은 이미 내려짐) / deep 세자가 운 때를 "처음 그 글이 내려졌을 때"로 밝힘 / "진심과 시험은 한 사람 안에" → "정말로 내놓고 싶은 마음과 신하들을 떠보는 마음이 … 있었을 것입니다"
- 4막 context: 가토를 막으라는 명이 있었다는 것을 밝힘(inner "왕이 내린 명"과 이어지게) / 부산 방화 보고 긴 문장을 둘로 / 원균이 누구인지 한 줄(선택지·이산해 대사에 처음 나오기 전)
- 4막 deep: "왕의 명은 그 자리 자체였습니다" → "신하가 왕의 명을 따르는 것이 곧 그가 왕이라는 증거" / 마지막 문장 뜻을 풀어 "그것도 왕의 마음을 편치 않게 했을 것입니다"
- 에필로그: 86명·18명 앞에 "명단에 오른 사람 가운데" / "피란이 옳았다고 남겨야 했습니다" → 주어·목적어를 밝혀 풀고 "…여겼을 것입니다"로 거리 / 영창대군 뒤에 "세자 광해군보다 서른한 살 어린 동생"(유언의 '형제'와 이어지게)
