## 작업 메모

### 설계 (2026-10-17)

- **축:** 행장 "帝自乙未以來，無人世之樂，而惟太皇帝是怙，依以爲命"(을미년 뒤로 세상의 즐거움이 없었고, 오직 아버지를 목숨처럼 기댔다). 1907년부터 자기 이름으로 나간 글은 거의 모두 남(내각·통감)이 썼고, 순종 자신의 글로 남은 것은 '거절'(1907.7.19 사양 두 번)과 아버지의 제사(1919 "惟喪葬祭，有我家法在", 배향공신)뿐. 물음은 "왜 골랐나"보다 "무엇이 하나씩 빠져나갔나, 그래도 무엇을 놓지 않았나".
- **흠:** 1907.7.19 뒤로 자기 이름의 글에 '싫다'고 한 기록이 다시 없음(2·4막 deep에서 "하지 못했는지, 하지 않았는지" 그대로 둠), "垂拱坐治"(행장 스스로 직접 다스리지 않았다고 씀), 순행 길에 황제 이름으로 일본 해군 칭송(3막), 아버지 시대 이야기를 아무도 못 하게 함 "汝輩何敢論先皇帝事乎"(5막).
- **후렴:** "\"을미년 뒤로 세상의 즐거움이 없었고, 오직 아버지를 목숨처럼 기댔다.\" / 순종이 세상을 떠난 뒤, 행장은 그의 삶을 이렇게 적었습니다."
- **장치 — 노란 점 마무리:** 단종(따름)·세조(찍음)·예종(지움)·명종(빈 점)을 마지막 편에서 다시 부름. 1막 아버지 고종의 조령(지울 수 없음) → 2막 이완용 내각(지울 수 없음) → 3막 통감 이토의 순행 계획(`erasable`, 점을 그대로 둔 것도 선택) → 4막 통감 데라우치·총리대신 이완용(지울 수 없음, overrule "실록에는 한 줄도 없습니다") → 5막 `markNone`(아버지 곁에 모실 신하 — 순종이 스스로 쓴 마지막 글). deep의 '선택지 밖의 길'은 그가 실제로 한 작은 일(사양의 글, 날마다 문안 전보, 임진왜란 장수 제사, 박규수·민영환 배향).
- **고리:** 고종편 4막(1895 을미사변)·에필로그(1907 대리, 1919) ↔ 프롤로그·1막·5막. 5막 박규수 ↔ 고종편 2막 묻기. 민영환 ↔ 고종편 에필로그. 에필로그 끝 "1392년 태조 이성계에서 시작한 스물일곱 왕의 이야기" ↔ EP01.
- **각색:** 프롤로그 narration("아버지가 쓴 글이 아니었다. 나는 안다" — 행장의 "以承順父皇之心爲心"에서), 3막 narration(통감이 권함 — 조서의 "特命陪扈"와 통설), 4·5막 inner. 5막 dial "신하들의 의논"은 행장 "衆議皆歸於勳戚平日密邇任事之人"을 옮긴 말.
- **나이:** 시리즈 기준(그 해 − 1874). 1882 여덟, 1884 열, 1895 스물하나, 1898 스물넷, 1907 서른셋, 1909 서른다섯, 1910 서른여섯, 1919 마흔다섯, 1921 마흔일곱, 1926 쉰둘. 영친왕 1897 → 1907 열. 행장 "享年五十三"은 세는나이.
