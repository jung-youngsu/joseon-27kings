### 공용 엔진으로 옮김 (2026-10-13)

- 옛 단일 `game.html`(자체 퀴즈·Supabase 기록 포함)을 `scenes.json` + 공용 엔진으로 옮겼다. 옛 판은 git 기록에 있다.
- **걷어 낸 것:** "연산군의 선택 / 이런 선택을 했었다면" 정답형, "당신은 옳은 선택을 알고 있었습니다", 막마다의 정조 비교, 출처 없는 숫자(52명·239명·122명), "백 년 동안 거론 말라", 임사홍 밀고 장면, 손톱자국.
- **남긴 것:** 막의 뼈대(어린 시절·삼사와의 다툼·무오·갑자·반정 전야)와 "막는 사람과 지키는 사람은 같은 사람이었다"는 4막의 생각.
- **축:** 아버지가 연 묻는 자리를 하나씩 닫은 아들. 그가 아버지에게서 물려받은 것은 묻는 법이 아니라 어머니의 죽음과, 아들을 위로하려다 아들을 막게 된 1489년 어서.
- **후렴:** "아버지는 묻는 자리를 열었고, / 아들은 그 자리를 닫았습니다."
- **먼저 묻기(`choice.ask`):** 성종편과 같은 장치. 물을 사람이 막마다 줄어든다 — 1막 셋, 2막 셋, 3막 둘, 4막 왕비 신씨 하나, 5막 없음.

### 쉬운 말 다듬기 (2026-10-16)
- scenes.json만 손봄 (48곳). 사실·순서·선택지·먼저 묻기(ask) 구조는 그대로.
- 처음 나올 때 풀이: 서연·경연·홍문관·사약·폐비·수라·기일·신주·사당·삼사·종묘·실록·사관·사초·대역·능지처사·참형·귀양·교서·후궁·인수대비·내관·언문(=한글)·투서·정언/지평·기녀·성균관·훈련원·묘호.
- 1막 deep 제목 「아버지의 어서」 → 「아버지가 남긴 글」, '백년지후' 뜻 한 줄 추가.
- 윤필상 says "선왕의 유교" → "돌아가신 임금께서 남기신 말씀" (유교=儒敎로 오해 방지), "신을 모실 곳" → "신주를 모실 곳".
- 무오사화·갑자사화에 해(무오년=1498, 갑자년=1504)를 함께 적음. 대간 → 삼사로 용어 통일.
- 무도 → 도리를 저버렸다, 혁파 → 없애라, 간쟁하는 관직 → 왕의 잘못을 따지던 벼슬, 역병 → 돌림병, 골육 → 피를 나눈.
- "증조할아버지 세조"가 성종 문장 안에서 헷갈리던 두 곳은 "세조"로만.
