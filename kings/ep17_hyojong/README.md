### 설계 (2026-10-16)

- **축:** 삼전도를 본 아들은 원수를 갚겠다고 마음먹었고, 그 마음을 드러낼 수 없었다. 그래서 청 앞에서는 숙이고(1막·3막), 청과 가까운 권신은 치웠고(2막), 원망 속에서도 군사를 길렀고(4막), 늘 시간이 없다고 느꼈다(5막). deep 끝에 「그는 왜 그랬을까」.
- **후렴:** "삼전도를 본 아들은 원수를 갚겠다고 마음먹었고, / 그 마음을 아무에게도 드러낼 수 없었습니다."
- **장치:** 1막(이경석·조석윤·조익)·4막(김육·이일상·원두표) 먼저 묻기, 2막 지울 수 있는 노란 점(삼사와 백관의 청 — 실록에 연일의 합계가 있음).
- **앞 편과의 고리:** 인조편 3막(삼전도) → 프롤로그, 인조편 4막(조소용의 참소) → 2막 조 귀인.

### 쉬운 말·문장·문맥 다듬기 (2026-10-16)

`scenes.json`만 손봄(49곳). 사실·막 순서·노란 점·먼저 묻기 구조는 그대로. 공용 낱말 사전(shared/glossary.js)에 있는 말은 괄호 풀이를 달지 않음.
- 쉬운 말: 치욕 → 부끄러운 일 / 권세 → 큰 힘 / 권신 → 힘센 신하 / 주관하였다 → 맡아 했다 / 위세·계책 → 기세·방법 / 은혜로 의리를 가릴 수 없다 → 정을 앞세워 법을 덮을 수는 없다 / 화의 뿌리 → 나쁜 일의 뿌리 / 군신의 약속 → 임금과 신하의 약속 / 족속 → 무리 / 군량 → 군사들이 먹을 양식 / 품계 → 벼슬 등급 / 하늘에 사무치다 → 하늘까지 닿다 / 침을 잡게 → 침을 놓게 / 공의를 따른다(선택지) → 조정의 뜻을 따른다, 법대로 다스린다 → 법대로 벌한다
- 첫 등장 풀이: 인질, 혼인(왕실 집안의 딸을 청으로 시집보내는 일), 사리, 통탄스럽다, 귀인, 옹주, 공의, 영고탑, 흑룡강, 군영, 사열, 대비(인조의 왕비)
- 깊게 2막 제목: 차마 형을 가하지 못하겠다 → 차마 형벌을 가하지 못하겠다(형=형님과 헷갈림)
- 프롤로그: 북벌이 무엇을 하려는 꿈인지, 들키면 안 되는 까닭 보충 / "심양에서 여덟 해" → "청에 붙잡혀 가 심양에서"
- 1막: "우리가 보낸 글" → "얼마 전 청에 보낸 글" / 핑계였다는 해석·김자점 의심 문장을 나눔 / 이경석이 "왕을 대신해 잘못을 짊어진 것" / 속마음 "속마음"이 무엇인지(청을 치려고 군사를 기르려는 마음) / 조익의 "두 가지 일만이 아닐 것" → "겉으로 내세운 일 때문만은 아닐 것"(앞에 나오지 않은 일) / 조경을 "또 한 신하"로 소개 / "그를 다시 데려왔다" → "그 신하를"

### 사실 확인 (2026-10-16)

- 2막 deep: 효명옹주까지 벌하라는 청(효종실록 2년 12월 3일 양사, 12월 14일 「三司、百官請逆趙母女按律」), 김자점 역모가 저주옥 수사 중 드러남(12월 7일 조인필 고변, 12월 13일 김식 공초), 김자점 정형 12월 17일(「사흘 뒤」) — 모두 확인.
- 2막 deep 「장례는 예를 갖추어 치러 주었다」 → 틀림. 12월 14일 「特令禮葬」 했다가 12월 15일 양사가 막자 「令只給葬需」. 퀴즈 해설도 같이 고침.
- 5막 deep 기해독대: 효종실록 10년 3월 11일 「上謂承旨李慶億曰：今日則承旨先出。上又命史官及宦寺竝退去，而時烈獨入侍，外廷之臣，不知所達何事」 — 만난 일은 실록에 있고 내용만 없음. 본문·study.md·퀴즈 17번 해설을 그렇게 고침.
