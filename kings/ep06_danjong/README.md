- **축:** 지켜 줄 사람이 없었던 아이. 이 편은 "그가 무엇을 했나"가 아니라 "아무것도 할 수 없던 아이를 두고 어른들은 무엇을 했나"를 묻는다.

### 주의

- 「단종실록」(원래 「노산군일기」)과 「세조실록」은 세조 쪽이 편찬했다. 단종이 "억지로 따랐다", "스스로 넘겼다"는 서술 모두 그 시각이다.
- 혜빈 양씨 양육, 세자 책봉 날짜(1450.7 / 1451.1 엇갈림), 청령포, 엄흥도 "爲善被禍 吾所甘心", 왕방연 시조는 실록 근거 없음 → "전합니다"로.
- 『고려사』 "1454 간행"은 부정확 — 1452.11 인쇄 계청, 1454.10 인간 논의.
- 나이(만): 즉위 1452 = 11, 정난 1453 = 12, 혼인 1454 = 13, 양위 1455 = 14, 1457 = 16. 정순왕후 1440년생.
