# 고려 혜종 왕무(912~945, 재위 943~945) 『고려사』 조사 노트

원문: 권2(세가 혜종), 권88(후비1 장화왕후·혜종 후비), 권90(종실1), 권92(박술희·최지몽), 권93(최승로 상서 — 오조정적평), 권127(반역1 왕규).
표시: ✔ 『고려사』 원문 확인 / ≈ 밖 / ✘ 못 찾음. 나이: 연도 − 912. 921 아홉, 936 스물넷, 943 서른하나, 945 서른셋. "壽三十四"는 세는나이.

## 1. 정윤까지
- 912(후량 건화 2년 임신) 출생, 태조 장자, 어머니 장화왕후 오씨 ✔(권2)
- 권88 장화왕후: 나주 목포 집안 · "以側微" · 돗자리 무늬 설화 · **"年七歲，太祖知有繼統之德，恐母微不得嗣位，以故笥盛柘黃袍，賜后。后示大匡朴述熙，述熙揣知其意，請立爲正胤。"** ✔ (7살은 세는나이)
- 921.12 정윤 책봉 ✔(권1 "冊子武爲正胤") / 권88 의화왕후 임씨 "太祖四年十二月，冊惠宗爲正胤，以后爲妃" ✔
- 932.7 정윤에게 북변 순행 ✔(권2) / 936.6 정윤이 보기 1만으로 천안부 ✔ / 권2 혜종 총서 "從討百濟，奮勇先登，功爲第一" ✔
- 943.5 태조 박술희에게 "卿扶立太子，善輔佐" ✔(권92) / 유명 "內外庶僚，並聽東宮處分" ✔

## 2. 945 왕규 — 권2, 권127
- 권2: "大匡王規，讒王弟堯及昭，王知其誣，恩遇愈篤。規又使其黨穴，壁入王寢內，謀作亂。王徙避之不問。" ✔
- 권127 왕규전: 태조 15·16비가 왕규의 딸, 16비 → 광주원군 ✔ / "規譖王弟堯及昭有異圖，惠宗知其誣，恩遇愈厚。" / 최지몽 **"流星犯紫微，國必有賊。"** → "惠宗意，規謀害堯、昭之應，乃以長公主妻昭，用强其族，規不得行其謀。" / "規又欲立廣州院君，嘗夜伺王睡熟，遣其黨潛入臥內，將行大逆。惠宗覺之，一拳斃之，令左右曳出，不復問。" / 신덕전 병중 최지몽 **"近將有變，宜以時移御。"** → 중광전 / "規夜率其黨，穴壁而入，寢已空矣。規見知夢，拔劒罵之曰：「上之移寢，必汝謀也」" / **"惠宗雖知規所爲，亦不罪之。"** ✔
- 권88 후광주원부인 왕씨 "大匡規之女" ✔(혜종 비) / 경화궁부인 임씨 "惠宗之女 … 乃以女妻昭，以强其勢" ✔

## 3. 마지막 — 권2
- **"王疾篤，群臣不得入見，憸小常侍側。戊申，薨于重光殿 … 自王規謀逆之後，多所疑忌，常以甲士自衛，喜怒無常。群小並進，賞賜將士無節，內外嗟怨。"** ✔ (945.9)
- 이제현 찬: "羽父請弑桓公 … 王規之譖兩王弟，亦羽父之意也。惠宗不致之罪，顧使居左右，其免於袖刃壁人之謀，可謂幸也 … 其未有以竄殛之，何也？嗚呼！小人之難遠也如此，可不戒哉？" ✔

## 4. 최승로의 평(982) — 권93
- **"惠宗，久在東宮，累經監撫，尊禮師傅，善接賓僚。由是，令名聞於朝野，及初卽位，衆擧欣然。時有人譖定宗兄弟，謂有異圖。惠宗聞而不答，亦無所問，恩遇愈豊，待之如初。故人皆服其大度。旣而不修德政，過惜身命，左右前後，常以甲士相隨，盖爲疑人太甚，大失爲君之體。加以偏賞將士，恩澤不均，故內外怨嗟，人心攜貳。又卽位踰年，便致沉痾 … 朝臣、賢士，不獲近前，鄕里小人，常居臥內。厥疾彌篤，嗔恚日增，三年之閒，民不見德。"** ✔

## 5. 그 뒤 — 권2·92·127
- 정종: "定宗知規有異志，密與西京大匡式廉謀應變。及規將作亂，式廉引兵入衛，規不敢動。乃竄于甲串，遣人追斬之，誅其黨三百餘人。" ✔ / 권2 정종 즉위 무신, 기유 왕규 복주 ✔
- 박술희: "及惠宗寢疾，述熙與王規相惡，以兵百餘自隨。定宗疑有異志，流于甲串，規因矯命殺之。" ✔
- 최지몽 포상 "褒知夢密奏事機" ✔

## 축
- 혜종 자신의 말은 남지 않음 ✘ → 후렴은 최승로 "惠宗聞而不答，亦無所問"(듣고도 대답하지 않고 묻지도 않았다). **"듣고도 묻지 않은 왕"**.
- 흠: 왕규를 끝내 벌하지 않음 → 두려움·의심·갑사·소인 측근·상 불공평("三年之閒，民不見德"). 왕규의 난을 정종 쪽 기록으로 보는 학설 ≈.
