# 고려 목종 왕송(980~1009, 재위 997~1009) 『고려사』 조사 노트

원문: 위키문헌 『高麗史』 — 권3(세가 성종 끝·목종), 권4(세가 현종1 서두), 권5(현종 끝 사신 최충 찬), 권88(열전 후비1 헌애왕태후·헌정왕후·선정왕후·궁인 김씨), 권93(한언공·최항·채충순), 권94(황보유의·하공진·안소광·조지린), 권123(폐행 유행간), 권127(반역 김치양·강조), 권78·79·81·82(식화지·병지). 캐시: scratchpad/gr/ws/v003.txt …
표시: ✔ = 『고려사』 원문 확인 / ≈ = 『고려사』 밖(전승·학설) / ✘ = 『고려사』에서 찾지 못함
나이: 사건 연도 − 980(경종 5년 경진 5월 임술 출생, 권3). 981 아버지 경종 죽음 한 살, 990 열(개령군), 997 열일곱(즉위), 1002 스물둘, 1003 스물셋, 1007 스물일곱, 1009 스물아홉(폐위·시해). 『고려사』 "壽三十"(1009, 권3)·"穆宗年己十八，太后攝政"(권88)은 세는나이.
어머니 헌애왕태후(천추태후) 황보씨: 1029년 "壽六十六"(권88, 세는나이) → 964년생쯤(≈ 셈). 1009년 마흔다섯쯤.

## 1. 태어남과 자람 (980~997) — 권3, 권88
- 980.5 임술 출생. "景宗長子。母曰獻哀太后皇甫氏" ✔. 아버지 경종은 이듬해(981.7, 경종 6년, 권2) 죽고 왕위는 경종의 사촌 동생 성종(목종의 당숙)에게 감 ✔.
- "成宗卽位，養于宮中。九年六月，封開寧君。" ✔ — 성종이 궁에서 길렀다. 990.6 개령군(열 살).
- 997.10 무오 성종이 병이 깊어 **"召開寧君誦，親降誓言傳位"**(개령군 송을 불러 몸소 맹세하는 말을 내려 자리를 물려줌) ✔ — 같은 날 "受內禪卽位" ✔. 성종은 죽기 직전 사면도 거절: "死生在天，何至釋有罪，枉求延命乎？" ✔(성종편)
- 997.12 임인 "尊母皇甫氏，爲王太后" ✔ / 권88: 존호 "應天啓聖靜德王太后" · **"穆宗年己十八，太后攝政，居千秋殿，世號千秋太后。"**(목종이 열여덟 살이어서 태후가 대신 정치를 하고 천추전에 살았으므로 세상에서 천추태후라 불렀다) ✔
  - 섭정 동안 태후가 무슨 정책을 냈는지는 『고려사』에 거의 없음 ✘. "凡忠臣義士，尤所忌憚，多以非罪陷之，穆宗不能禁"(충신을 꺼려 죄 없이 빠뜨렸고 목종이 막지 못했다) ✔ 권88 — 평가 문장.

## 2. 즉위 초의 정치 (998~1002) — 권3, 권78·79·81·93
- 998.4 성종을 태묘에 모시고 최승로·최량 배향, 왕의 생일을 장령절로 ✔. 998.7 서희 죽음 ✔. 서경을 호경으로 ✔.
- **998.12 전시과 고침**: "改定文武兩班及軍人田柴科" ✔(권78 식화지) — 교과서의 '개정 전시과'. 세가에는 없음, 지(志)에만 있음.
- 999 진관사(태후 원찰) ✔, 1000 숭교사 ✔ — 1003년 대량원군이 머리를 깎인 절이 이 숭교사(권4) ✔.
- 999.10 송에 주인소를 보냄 → **"仁紹自陳國人思慕華風，爲契丹劫制之狀"**(우리 나라 사람들은 중국 문화를 그리워하나 거란에 억눌려 있다고 하소연) ✔ — 거란에 사대하면서 송과 몰래 끈을 이음.
- 1001.11 중원부(충주) 순행 ✔ / 권93 한언공전: 장단현에서 "此卿本貫也 … 可陞爲湍州" ✔.
- 권93 한언공전 — **평주 행차에서 날이 저물고 추운데 "駐輦道傍，酣飮不行"**(길가에 수레를 세우고 취하도록 마시며 가지 않음) → 한언공 **"臣等醉飽，柰軍士何？"**(저희는 취하고 배부르지만 군사들은 어찌합니까) → "王嘉之，賜貂鼠裘，趣駕入行宮" ✔ (연도 미상) — 흠과 들을 줄 앎이 한 장면에.
- **1002.7 화폐**: 성종 때 철전을 만들어 쓰게 했으나 한언공 상소 "今繼先朝而使錢，禁用麤布，以駭俗，未遂邦家之利益，徒興民庶之怨嗟"(선왕을 이어 돈을 쓰게 하고 거친 베를 금하니 백성이 놀라고 원망만 커진다) → 목종 교서 **"朕方知啓沃之精詞，詎可弃遺而不納？便存務本之心，用斷使錢之路。其茶酒食味等諸店交易，依前使錢外，百姓等私相交易，任用土宜。"**(짐이 이제야 일깨워 주는 좋은 말을 알았으니 어찌 버리고 듣지 않겠는가. 근본에 힘쓰는 마음으로 돈 쓰는 길을 끊는다. 찻집·술집·음식점 거래는 전처럼 돈을 쓰되, 백성끼리 사사로이 사고팔 때는 그 땅에 나는 물건을 마음대로 쓰게 하라) ✔ 권79 ★
- **1002.5 스스로를 꾸짖는 교서**: **"不揣心之所欲，謂爲時之可行。或不念居安思危 … 廣徵土木，勞役軍夫，築高臺而作深池，爲資遊賞，役人戶而造佛寺 … 此雖皆從執奏而施行，豈非一人之失德？"**(내 마음이 하고 싶은 것을 헤아리지 않고 지금 해도 되는 일이라 여겼다. 편안할 때 위태로움을 생각하지 않고 … 군사와 일꾼을 부려 높은 대와 깊은 못을 만들어 놀이에 쓰고, 백성을 부려 절을 지었다. 이것이 모두 신하들이 아뢴 대로 한 것이라 해도 어찌 나 한 사람의 잘못이 아니겠는가) → "何異截羽翼而欲高飛"(날개를 자르고 높이 날려는 것과 무엇이 다르랴) → **"各成六衛軍營 … 令其軍士，蠲除雜役"**(6위 군영을 갖추고 군사들의 잡일을 덜어 주라) ✔ 권3 (권81 병지도 "穆宗五年五月，作六衛軍營" ✔) ★
- 성 쌓기: 1000 덕주, 1001 영풍·평로진, 1003 덕주 등 4성, 1005 진명현·금양현·곽주 ✔ 권82 — 뒤에 거란 2차 때 버틴 곽주·흥화 쪽 방비가 이때부터.

## 3. 김치양과 천추태후 (1003~1008) — 권3, 권88, 권127, 권123
- **1003 "是年，太后皇甫氏與金致陽通，生子。謀爲王後，逼大良君詢爲僧。"**(이 해 태후가 김치양과 정을 통해 아들을 낳고, 그 아이를 왕의 뒤로 세우려 대량군 순을 억지로 중이 되게 했다) ✔ 권3
- 권127 김치양전: 천추태후의 외가 쪽 친척. 성종 때 "嘗詐祝髮，出入千秋宮，頗有醜聲。成宗認之，杖配遠地"(가짜로 머리를 깎고 드나들어 추문 → 성종이 매 때려 멀리 귀양) ✔ / **"穆宗卽位，召授閤門通事舍人，不數年，貴寵無比，驟遷至右僕射兼三司事。百官與奪，皆出其手"** ✔ / 집 300여 칸, 동주에 성수사, 궁성 서북에 십왕사 ✔
  - **"穆宗常欲黜之，恐傷母志，不敢也。"**(목종은 늘 그를 내치려 했으나 어머니 마음이 다칠까 두려워 하지 못했다) ✔ ★ — 축 후보.
- 권88: 태후가 신혈사의 대량원군에게 독을 탄 술과 떡을 보냄 → 절의 중이 굴에 숨기고 "小君出遊山中" → 떡을 뜰에 버리니 "烏雀食而卽斃" ✔
- **1004.3 과거법 고침**(3월 시험, 경전·시부·시무책 순서) ✔ 권3·권73 / 1005.3 "汰外官"(지방관 줄임) ✔ / 1005 송 온주 사람 주저가 옴 → 채충순이 남게 함 ✔ 권94 / 1006.6 천성전 벼락 → "王憂懼，責己肆赦" ✔ / 1006 "詔：文班常參以上，各擧才堪治民者一人" ✔ 권75.
- **1003.2 신하들에게 바른말 청하는 교서**: **"余幼失義方，長無師訓。臨朝蒞事，慄慄兢兢。"**(나는 어려서 바른 가르침을 잃었고, 자라서도 스승의 가르침이 없었다. 조정에 나가 일을 볼 때마다 떨리고 조심스럽다) / **"今見上自台輔，下至庶僚，曾無謇諤之言，但有阿諛之說。"**(지금 보니 재상부터 낮은 관리까지 곧은 말은 없고 아첨하는 말뿐이다) → 5품 이상 봉사 ✔ 권3 ★ (6년 2월 신유)
- 1003.1 교서 "予謬以眇冲，嗣守艱大" · 지방 학교 권장 ✔.
- **1007 궁인 김씨 사건**(권88): 총애하던 '요석택 궁인' 김씨에게 경주 사람 융대가 양민 500여 명을 노비라 속여 바치고 평장사 한인경·시랑 김낙에게도 줌 → 어사대가 밝힘 → **"穆宗命罰金氏銅一百斤，流藺卿、諾于外。聞者皆賀。"**(목종이 김씨에게 구리 100근을 물리고 인경과 낙을 귀양 보내니, 들은 사람이 모두 기뻐했다) ✔ / 세가 1007.7 무인 "流平章事韓藺卿于楊州，吏部侍郞金諾于海島" ✔ — 아끼는 사람도 벌한 일. (김치양은 끝내 못 벌함 — 대조)
- 권123 유행간전: **"行簡姿美麗，穆宗嬖愛，有龍陽之寵。"**(행간이 아름다워 목종이 지나치게 아꼈다 — '용양의 총애'는 남자를 사랑한 것을 가리키는 옛말) ✔ / **"每宣旨，必先問行簡然後行 … 近侍視之如王"**(왕명을 낼 때 반드시 행간에게 먼저 물었다 … 곁의 사람들이 그를 왕처럼 보았다) ✔ / 발해 출신 유충정도 총애 ✔. → 게임에서는 *"왕이 지나치게 가까이 둔 신하"* 정도로 쓰고, 심화에 원문 표현을 밝힐지 판단.
- 1007.2 거란이 책봉 ✔ / 1007 진관사 9층탑 ✔ / 1005.1 동여진이 등주를 침 ✔.

## 4. 1009 마지막 한 달 — 권3, 권93, 권94, 권127
- **1009.1 임신** 상정전 관등 → 대부 기름 창고 불이 천추전까지 → **"王見殿宇府庫煨燼，悲嘆成疾，不聽政。"**(궁궐과 창고가 잿더미가 된 것을 보고 슬퍼하다 병이 나 정사를 듣지 않았다) ✔ — 밤낮 숙직 명단: 유진·최항·채충순(은대), 유행간·유충정(안), 하공진·탁사정 등 전문 ✔.
- "王累日不豫常居於內厭見群臣。宰臣震恐請入寢問疾不許。" ✔ — 유행간이 "體氣漸平，取別日召見" 하며 재상을 막음 ✔ 권123.
- **권93 채충순전 — 후계를 정하는 장면** ✔ ★
  - 왕이 채충순을 침실로 불러: "寡人疾漸就平。聞外閒有窺覦者，卿知之乎？" → 유충정의 고발 편지(김치양이 "覬覦非望") + **대량원군의 편지 "姦黨遣人圍逼。遺酒食，臣疑毒不食，與烏雀，烏雀斃。謀危若此，願聖上憐救。"**(간사한 무리가 사람을 보내 에워싸고 술과 음식을 보냈는데, 독이 의심되어 먹지 않고 까마귀와 참새에게 주니 죽었습니다. 이렇게 위태로우니 불쌍히 여겨 구해 주십시오)
  - 충순 "勢急矣，宜早圖之。" → 왕 **"朕疾漸危篤，朝夕入地，太祖之孫，唯大良院君在。卿與崔沆，素懷忠義，宜盡心匡扶，使社稷不屬異姓。"**(짐의 병이 위독해 곧 땅에 들 것이다. 태조의 손자로는 대량원군만 남았다. … 나라가 다른 성씨에게 넘어가지 않게 하라)
  - 왕 **"予欲親禪，可亟遣不可緩也。若疾瘳，如成宗封朕故事，早定名分，則無窺伺之人矣。朕無子而繼嗣未定，衆心搖動，是吾過也。"**(내가 직접 물려주고 싶으니 서둘러 보내라. 병이 나으면 성종께서 나를 봉하신 옛일처럼 일찍 이름을 정해 엿보는 사람이 없게 하겠다. 짐이 아들이 없고 뒤를 정하지 않아 사람들 마음이 흔들린 것은 내 잘못이다) → **"王遂泣下，忠順亦泣。"** ★
  - 편지를 쓰게 하며 몸소 먹을 갈자 충순이 말림 → 왕 **"意甚忙，不覺勞也。"**(마음이 매우 급해 힘든 줄 모르겠다) ✔ ★
  - 편지: "卿太祖嫡孫，宜速上道。寡人未至大期，得面付宗社，沒無遺恨。" / 끝에 "道路險阻，恐姦人潛伏 … 可戒愼而來" ✔
  - **"時閤門舍人庾行簡不欲迎立，王慮事泄，戒忠順，勿令行簡知之。"**(가장 아끼던 유행간이 반대하자 왕은 그에게 알리지 말라 했다) ✔ — 아끼던 사람을 이 일에서는 뺐다.
  - 황보유의를 고른 까닭 "志存宗社，且其父祖，有勳勞於國" ✔ 권94 / 군사를 적게: "軍校多，則行必遲，恐姦黨先啚。宜遣十餘人" ✔
- **강조를 부른 것**(권127 강조전): **"穆宗寢疾，知金致陽謀變，遣皇甫兪義，往迎顯宗。又知殿中監李周楨附致陽，權授西北面都巡檢副使，卽日發遣，仍徵兆入衛。"**(김치양 편인 이주정을 서북면으로 내보내고, 서북면 도순검사 강조를 불러 궁을 지키게 했다) ✔ ★
  - 위종정·최창이 강조에게 "主上疾篤，命在頃刻，太后與致陽謀奪社稷 … 矯命徵召"라 속임 ✔ / 태후가 절령을 막음 ✔ / 강조 아버지의 대지팡이 편지 "王已賓天，姦兇用事" — 심부름한 종이 "氣竭而斃" ✔
  - 평주에서 "知王未薨，兆喪氣，垂頭良久" → 여러 장수 **"業已來矣，不可止。"** → 강조 "然。" "遂決意廢立" ✔ ★ — 강조도 처음에는 왕을 몰아낼 생각이 아니었다.
  - 강조의 상주: "又偏信庾行簡等讒諛，賞罰不明，致此危亂 … 請出御龍興歸法寺" → 왕 "已知所奏" ✔
- **1009.2 무자·기축** "日色如張紅幕" ✔ → 강조 군사 궁문 난입 → 목종이 놀라 **"執行簡送兆所"**(유행간을 잡아 강조에게 보냄) ✔ 권127 / **"王知不免，與太后號泣，出御法王寺"** ✔ / 최항이 강조에게 **"古有如此事乎？"**(예로부터 이런 일이 있었소?) — 강조 대답 없음 ✔ / 군사들 만세에 강조 "嗣君未至，是何聲耶？" ✔
- 대량원군 즉위(연총전) → **목종을 양국공으로 폐함, 김치양 부자·유행간 등 7명 죽임, 태후 친족 30여 명 섬으로** ✔
- **폐위 뒤**: 선인문으로 나와 귀법사에서 **"解御衣，換食而進"**(입던 옷을 벗어 먹을 것과 바꿔 드림) ✔ / 최항에게 **"頃府庫災而變起所忽，皆由予不德，夫復何怨？但願歸老于鄕，卿可奏新君，且善輔佐。"**(창고에 불이 나고 뜻밖에 변이 일어난 것은 모두 내가 덕이 없어서이니 무엇을 원망하겠는가. 다만 고향에 돌아가 늙기를 바랄 뿐이다. 경은 새 임금에게 아뢰어 잘 도우라) ✔ ★ / 충주로 향함 / **"太后欲食，王親奉盤盂，大后欲御馬，王親執鞚。"**(태후가 먹으려 하면 왕이 몸소 그릇을 받들고, 말을 타려 하면 몸소 고삐를 잡았다) ✔ ★
  - 강조가 말 한 필을 보내고, 또 민가에서 한 필 ✔ 권127.
- **적성현에서 시해**: 강조가 상약직장 김광보를 시켜 독 → **"穆宗不肯飮"** → 중금군 안패 등이 밤에 죽이고 "以自刎聞"(스스로 목을 찔렀다고 알림), 문짝으로 관을 만듦 ✔ 권3·권127. "王在位十二年，壽三十" ✔
- 뒤처리: 한 달 뒤 화장, 능 공릉, 시호 선령·묘호 민종 **"皆康兆所撰定"** ✔ / **"臣民莫不痛憤，而顯宗未之知，至契丹問罪，始知之。"**(신하와 백성이 모두 분했으나 현종은 몰랐다가 거란이 죄를 물으러 오자 비로소 알았다) ✔ — 현종편으로 / 1012 현종이 동쪽으로 옮겨 묻고 의릉·선양·목종으로 고침 ✔.
- 김치양의 아들(천추태후의 아들)은 이름도 나이도 『고려사』에 없음 ✘ — "殺致陽父子" ✔ 뿐.
- 천추태후는 황주로 가서 21년 살다 1029.1 숭덕궁에서 죽음 ✔ 권5·권88.

## 5. 평가 — 누가 썼나
- 권3 세가 끝(편찬자 서술, 조선): **"性沈毅，少有人君之度。善射御。嗜酒好獵，不留意政事，信狎嬖倖，以及於禍。"**(성품이 침착하고 굳세어 어려서 임금의 풍모가 있었고 활쏘기·말타기를 잘했다. 술을 즐기고 사냥을 좋아해 정사에 마음을 두지 않았으며, 아끼는 신하를 믿고 가까이하다 화를 입었다) ✔ — 『고려사』 편찬자(조선) 문장. 앞의 교서들(1002·1003)과는 결이 다름.
- 이제현 찬(고려 말): **"穆宗不戒覆車之轍，防閑於初，子母俱罹其殃，社稷幾至於亡。鳴呼！宣讓之不幸也，抑非不幸也。"**(목종은 앞 수레가 엎어진 바퀴 자국을 경계해 처음부터 막지 않았으니 어머니와 아들이 함께 화를 입고 나라가 거의 망할 뻔했다. 아, 목종의 불행이여, 아니 불행만은 아니로다) ✔ — 진시황 어머니·노애 고사로 태후 문제를 꼬집음.
- 권5 사신 최충 찬(현종 때 고려 사관): **"千秋太后，自縱滛荒，潛圖傾奪，穆宗知百姓之屬望，排千秋之惡黨。遠馳使命，以授神器"**(천추태후는 제멋대로 음란하여 몰래 나라를 빼앗으려 했으나, 목종이 백성의 바람을 알고 천추의 악한 무리를 물리쳐 멀리 사신을 보내 왕위를 주었다) ✔ — 현종의 정통성을 말하는 쪽의 기록. 천추태후를 정치가로 다시 보는 학설 ≈.
- 1027.4 현종이 목종 묘정에 한언공·김승조·최숙 배향 ✔ 권5.

## 축(제안)
- **"恐傷母志"(어머니 마음이 다칠까) → "끊어 내지 못한 왕"**. 자기 탓은 말할 줄 알았다: 1002 "豈非一人之失德", 1003 "余幼失義方，長無師訓", 1009 "朕無子而繼嗣未定 … 是吾過也", 폐위 뒤 "皆由予不德，夫復何怨". 아끼는 궁인 김씨는 벌했고(1007), 한언공 말에 돈 정책을 거두었다(1002). 그러나 어머니와 김치양만은 끝내 끊지 못했다 — 그리고 마지막 길에도 어머니의 그릇을 받들고 고삐를 잡았다.
  - 중심 질문 연결: 아버지(경종)를 한 살에 잃고 당숙 성종의 궁에서 자람 → 기댈 사람은 어머니 → "余幼失義方"이라 스스로 말함. *"그래서 어머니를 끊지 못한 것이 이해된다"*.
- 다른 한 줄 후보: "意甚忙，不覺勞也"(마음이 급해 힘든 줄 모르겠다) — 늦게, 그러나 끝내 스스로 고른 후계.
- 흠: 술·사냥·놀이용 토목(본인이 1002 교서에서 인정), 평주의 "酣飮不行", 유행간·유충정에게 왕명을 먼저 묻게 한 일, 재상을 침실에 들이지 않음, 김치양을 알고도 둠("恐傷母志"), 태후가 충신을 빠뜨려도 "不能禁", 후계를 늦게 정함("是吾過也"), 강조를 부른 판단(결과적으로 자기 목숨), 마지막에 유행간을 잡아 강조에게 넘김.

## 막 후보
1. **1002 — 돈을 계속 쓰게 할 것인가** (스물둘)
   - 상황: 성종(길러 준 당숙)이 시작한 철전 사용. 거친 베를 금하자 백성이 원망. 시중 한언공이 상소.
   - 실제로 하지 않은 두 길: ① 선왕이 정한 법이니 그대로 밀어붙인다 ② 돈을 아예 없애고 베로 되돌린다.
   - 실제: 가게(차·술·음식점)에서만 돈, 백성끼리는 "任用土宜" — **"朕方知啓沃之精詞，詎可弃遺而不納？"** ✔ 권79
   - 말: 한언공 "今繼先朝而使錢，禁用麤布，以駭俗 … 徒興民庶之怨嗟" ✔
2. **1002.5 — 놀이를 위한 공사, 누구의 잘못인가** (스물둘)
   - 상황: 높은 대·깊은 못·절 공사로 군사들이 원망. 신하들이 아뢰어 시작한 일들.
   - 하지 않은 길: ① 신하들이 아뢴 일이니 그들을 벌한다 ② 조용히 공사만 멈춘다.
   - 실제: 교서로 스스로 탓함 "此雖皆從執奏而施行，豈非一人之失德？" + 6위 군영, 군사 잡역 면제 ✔ 권3
3. **(1003~1008) — 김치양을 내칠 것인가** (스물셋~스물여덟)
   - 상황: 어머니의 사람 김치양이 인사를 쥐고, 어머니가 그의 아들을 낳아 왕의 뒤로 세우려 함. 대량원군은 머리를 깎이고 독 음식을 받음.
   - 하지 않은 길: ① 성종이 했듯 김치양을 매 때려 귀양 보낸다 ② 어머니를 따로 떨어진 궁으로 모신다.
   - 실제: 두었다 — **"穆宗常欲黜之，恐傷母志，不敢也。"** ✔ 권127. (해마다 날짜가 있는 장면이 아님 — 막으로 세우면 '고른 자리'가 '고르지 않은 자리'가 됨. 1009 막의 앞 장면으로 붙이는 편이 나을 수 있음)
4. **1009.1 — 누구에게 나라를 줄 것인가** (스물아홉) ★ 중심
   - 상황: 천추전 화재 뒤 병석. 김치양이 엿본다는 고발과 대량원군의 구원 편지가 한꺼번에 머리맡에.
   - 하지 않은 길: ① 병이 나을 때까지 기다리며 아무에게도 알리지 않는다 ② 어머니에게 맡긴다(태후의 아들).
   - 실제: 채충순·최항과 몰래 의논, 황보유의 등 열 명을 신혈사로, 먹을 몸소 갈며 편지 — "朕無子而繼嗣未定，衆心搖動，是吾過也", "意甚忙，不覺勞也". 아끼던 유행간에게는 알리지 않음 ✔ 권93
   - 말: 채충순 "勢急矣，宜早圖之。" / 최항 "臣常以爲憂，今上意如此，社稷之福也。" ✔
5. **1009.1 — 누구에게 궁을 지키게 할 것인가** (스물아홉)
   - 상황: 김치양 편이 궁 안팎에. 서경 쪽 군대를 쥔 사람은 강조.
   - 하지 않은 길: ① 궁 안 친위군(유방·탁사정·하공진)만으로 버틴다 ② 강조를 서북에 그대로 두고 대량원군 맞이를 먼저 끝낸다.
   - 실제: 이주정을 서북으로 내보내고 **"仍徵兆入衛"** ✔ 권127 → 강조가 속아 군사를 일으켰다가, 평주에서 왕이 살아 있음을 알고도 "業已來矣，不可止" → 폐위·시해.
   - 에필로그 재료: "皆由予不德，夫復何怨？但願歸老于鄕" · 어머니의 그릇과 고삐 · "穆宗不肯飮".
