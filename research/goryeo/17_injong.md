# 고려 인종 왕해(王楷, 1109~1146, 재위 1122~1146) 『고려사』 조사 노트

원문: 위키문헌 『高麗史』 — 권13·14(세가 예종), 권15(세가 인종1), 권16(인종2), 권17(인종3·찬), 권58(지리지), 권88(후비1), 권90(종실1), 권96(열전 김인존·윤언이), 권97(한안인·이영), 권98(김부식·정습명·고조기·최사전), 권127(반역1 이자겸·척준경·묘청). 캐시: scratchpad/gr/ws/v015.txt …
표시: ✔ = 『고려사』 원문 확인 / ≈ = 『고려사』 밖(전승·학설) / ✘ = 『고려사』에서 찾지 못함
이름: 휘 楷, 자 仁表, **옛 휘 構**(1114.11 예종이 '構'라 이름 줌 ✔).
출생: 1109(예종 4) 10월. 권15는 "十月己亥", 권13은 "冬十月乙亥，元子構生" — **일진이 서로 다름** ✔. 어머니 순덕왕후(이자겸의 둘째 딸)가 "生元子於私第"(친정에서 낳음) ✔(권88).
나이: 사건 연도 − 1109. 1115 여섯(왕태자), 1118 아홉(어머니 사망), 1122 열셋(즉위), 1124 열다섯(이자겸 셋째 딸과 혼인), 1125 열여섯(넷째 딸), 1126 열일곱(이자겸의 난), 1127 열여덟(첫 서경 행차·묘청 등장, 의종 출생), 1129 스물(서경 대화궁), 1132 스물셋, 1134 스물다섯, 1135 스물여섯(묘청의 난), 1136 스물일곱(서경 함락), 1145 서른여섯(『삼국사기』), 1146 서른일곱(세상 떠남). 『고려사』 "壽三十八"은 세는나이.
주변 인물: 이자겸 생년 ✘(나이 쓰지 않음). 김부식 — 1151 "年七十七"(세는나이, 권98) → 1075년쯤 ≈ → 1135 원수가 될 때 예순쯤. 척준경 1144 사망 ✔(생년 ✘). 아들 의종 1127.4 생 ✔.

## 1. 열세 살 왕과 외할아버지 (1122~1125) — 권15, 권127, 권98, 권97
- **1122.4 즉위**: **"諸弟以王幼，頗有覬覦心，平章事李資謙奉王，卽位于重光殿"**(삼촌들이 왕이 어리다고 자리를 넘보는 마음이 있었는데, 이자겸이 왕을 받들어 즉위시켰다) ✔ — 이자겸이 '지켜 준 사람'으로 시작.
  - 아버지의 유언 "太子雖在幼少，德行宿成，諸公同心恊輔" ✔(권14)
  - "朝夕奠殯，哭踊盡哀，左右侍臣哀慟不能止" ✔
- 1122.5 이자겸 협모안사공신·수태사·중서령·소성후 ✔ / 어머니를 문경왕태후로 추존 ✔
- 이자겸 예우 논쟁(권98 김부식전): 정극영·최유 "后之父母"는 신하로 대하지 않는다 → 표에 '신'이라 쓰지 말자. **김부식만 반대**: 공적인 자리에서는 군신의 예, 궁 안에서는 가족의 예("在王庭，則行君臣之禮，宮闈之內，則以家人禮相見") ✔. 이자겸: "臣雖無知，今觀富軾議，實天下之公論也" ✔ — 이자겸도 처음엔 체면을 차림.
- **1122.12 丙申 대숙청**: 삼촌 대방공 보를 경산부로, 한안인 살해, 문공미·정극영·이영 등 유배 ✔. 권97 한안인전: 한안인이 이자겸을 "陽尊資謙，封爲上公，不令視事，陰欲奪其權"(겉으로 높여 상공으로 앉히고 일은 못 하게 해 몰래 권력을 빼앗으려) → 최사전(예종을 오진해 한안인이 벌하려 했던 의원)이 "安仁、公美，結黨陰謀，將不利於李令公"이라 이간 → **"流安仁于昇州甘勿島，沉殺之"**(섬으로 귀양 보내 물에 빠뜨려 죽였다) ✔. 이영은 "飮酒一斗，憤懣而卒" ✔. 『고려사』 기사에 열세 살 왕이 이 결정에 무엇을 했는지는 ✘.
- 1123.6 송 사신 노윤적·서긍 ✔(서긍 『고려도경』에 김부식 기록 ✔ 권98). 송이 '이제 요가 망했으니 송의 책봉을 청하라' → 인종: **"所謂冊命，天子所以褒賞諸侯之大典也，今憂制未終，而遽求大典，於義未安"**(책봉은 천자가 제후에게 주는 큰 상인데 아직 상중이라 급히 구하는 것은 옳지 않다) ✔
- **1124.7 이자겸 조선국공**, 1124.8 대사면 교서: **"欲尊外家之長，以慰先后之靈"**(외가의 어른을 높여 돌아가신 어머니의 넋을 위로하려 한다) ✔ ★ — 인종의 마음(어머니를 일찍 잃음).
- **1124.8 戊午 이자겸이 셋째 딸을 왕에게** / **1125.1 庚寅 넷째 딸** ✔. 권127: **"資謙恐他姓爲妃，權寵有所分，强請納第三女于王，王不得已從之。是日大風，飛瓦拔木"**(다른 성씨가 왕비가 되어 권세가 나뉠까 두려워 셋째 딸을 억지로 들이게 하니 왕이 어쩔 수 없이 따랐다. 그날 큰바람이 불어 기와가 날고 나무가 뽑혔다) ✔ — 두 왕비는 인종의 **이모** ("宮主於上，爲從母" 권88) ✔.
- 이자겸의 횡포(권127): 생일을 '인수절'이라 부름(김부식 반대 ✔ 권98), 송에 따로 표를 올려 "自稱知軍國事" ✔, **"腐肉常數萬斤"**(선물로 들어온 고기가 썩는 것이 늘 수만 근) ✔, 남의 땅을 빼앗고 종들이 수레·말을 빼앗아 "小民皆毁車，賣牛馬，道路騷然" ✔. "又欲知軍國事，請王幸其第授策，勒定時日。事雖未就，王頗惡之"(군국사를 맡겠다며 왕더러 자기 집에 와서 임명하라고 날짜까지 정했다. 이루지 못했으나 왕이 몹시 미워했다) ✔
- 1125.5 금에 사신 → "金以國書非表又不稱臣不納" ✔ / 1125 금이 요를 멸망 ✔

## 2. 1126 이자겸의 난 — 권15, 권127, 권96, 권98
- **난 전에 인종이 먼저 물음**(권96 김인존전): **"王密遣內侍金安，問於仁存及李壽曰：「欲奪資謙權，置散地，如何。」皆對曰：「上生長外家，恩不可絶。況彼黨與滿朝，不可輕動，請俟其閒。」王不聽。"**(왕이 몰래 김안을 보내 '이자겸의 권력을 빼앗아 한가한 자리로 보내면 어떻겠는가' 물었다. 둘 다 '임금께서는 외가에서 자라셨으니 은혜를 끊을 수 없고, 저쪽 무리가 조정에 가득하니 가벼이 움직이면 안 됩니다. 틈을 기다리소서' 했으나 왕이 듣지 않았다) ✔ ★
- **1126.2 辛酉** 내시 김찬·안보린이 "揣知王意"(왕의 뜻을 짐작하고) 지녹연·최탁·오탁·권수·고석과 함께 밤에 궁에 들어가 척준신(척준경 동생)·척순(척준경 아들) 등을 죽임 ✔(권127)
  - 척준경: **"事急矣，不可坐待。"** → 궁을 에워쌈, 승려 의장이 현화사 승려 300여 명을 데려옴 ✔
  - **신봉문 장면**: 인종이 누각에 황색 일산을 펴고 나서자 군사들이 절하며 만세 → 왕 **"汝輩，何爲操兵而至？"** / 군사 "聞有賊入禁中，欲衛社耳" / 왕 **"無之，朕亦無恙，汝等可釋甲散去。"**(그런 일 없다. 짐도 무사하니 갑옷을 벗고 흩어져라) → 은을 내려 줌 → 척준경이 칼로 쫓아내고 다시 무장, **"或有流矢及御前，以楯蔽之"**(화살이 왕 앞까지 날아와 방패로 막았다) ✔ ★
  - 2.壬戌 척준경이 동화문 행랑에 불을 지름 → 궁궐이 탐 ✔. 이수가 "宮宇相比，延燒不可撲滅，甚不可也"라 반대했으나 기다리지 않음 ✔
  - **산호정의 밤**: **"夜王步至山呼亭，侍從皆散，惟近臣林景淸等十餘人在。王恐被害，作書，請禪位於資謙"**(밤에 왕이 걸어서 산호정에 갔는데 시종은 다 흩어지고 10여 명만 남았다. 왕이 죽을까 두려워 이자겸에게 왕위를 넘기겠다는 글을 썼다) ✔ ★ → 이수 **"上雖有詔，李公豈敢如是？"**(임금께서 조서를 내리셔도 이공이 어찌 감히 그러겠소) → 이자겸 울며 글을 돌려보냄 **"臣無二心，惟聖鑑諒之。"** ✔
  - 산호정에서 인종 **"恨不用金仁存之言，以至於此。"**(김인존의 말을 듣지 않아 이 지경이 된 것이 한스럽다) ✔(권96) ★
  - 홍관입공: "我與若等，皆王臣也，而負薪燒宮，非臣子之義" — 나뭇짐을 버리고 왕 곁으로 ✔
  - 2.癸亥 남궁으로 옮김, 태조 이하 진영을 내제석원 우물에 숨김 ✔. 오탁·좌복야 홍관 등 17명, 군사 "不可勝計" 죽음 ✔. 왕이 "請勿殺"이라 해도 이지보가 다 죽임 ✔
  - 이자겸 집(중흥택 서원)으로: 지석숭이 왕의 옷을 붙잡고 살려 달라 해 **"御衣爲之裂，幞頭亦觸楣而破"** ✔. 이자겸 부부가 땅을 치며 울음: **"自皇后入宮，願生太子，及聖人誕生，祈天永命，無所不至 … 不圖今日反信賊臣欲害骨肉。」王羞赧無言"**(딸이 궁에 들어간 뒤로 태자 낳기를 빌었고, 태어나신 뒤엔 오래 사시길 빌지 않은 것이 없는데, 오늘 도리어 역적의 말을 믿고 혈육을 해치려 하시다니 — 왕은 부끄러워 말이 없었다) ✔ ★
- 갇힌 왕: "國事不自聽斷，動止飮食，皆不自由" ✔ / 1126.4 안화사에 가며 **"王回望舊宮，泫然淚下"** ✔ / **"王嘗獨往北垣，仰天慟哭移時"**(홀로 북쪽 담장에 가서 하늘을 보며 한참 울었다) ✔
- **독이 든 떡**: 이자겸이 "十八子"(李) 참언을 믿고 떡에 독 → **넷째 딸 왕비가 몰래 알려 까마귀에게 던지니 죽음**, 또 약을 보내자 왕비가 그릇을 들고 일부러 넘어져 엎음 ✔(권127, 권88) ★
- **1126.3 금을 섬길까**: 백관 "皆言不可" / **"獨李資謙、拓俊京曰：「金昔爲小國，事遼及我。今旣暴興，滅遼與宋，政修兵强 … 且以小事大先王之道，宜先遣使聘問。」從之。"** ✔ → 1126.4 칭신 표 ✔. 갇힌 상태의 결정이라 인종의 뜻인지는 ✘ — 다만 김부식 찬은 "及金國暴興，排群議，上表稱臣"을 인종의 공으로 적음 ✔(5절).
- **척준경을 돌리다**(권127, 권98 최사전전): 왕이 의원 최사전과 꾀함. 최사전 **"資謙所以跋扈者，惟恃拓俊京。若得俊京，則兵權內屬，資謙特一夫耳。"** / 왕 **"俊京爲國公腹心，至結婚姻，而弟俊臣、子純，皆爲官兵所害，以是疑之。"** → "乃筮得吉兆" ✔. 왕이 척준경에게 조서: **"惟朕不明，致兇徒生事，使大臣憂勞，皆寡人之罪 … 卿其更勵厥脩，無念旣往，盡心夾輔"** ✔
  - 이지언의 종과 척준경의 종이 다툼("汝主射宁位，火宮禁，罪當死") → 둘이 틀어짐 ✔
  - 척준경이 "願自効" → 인종: **"國公雖僭亂，反狀未著。朕若先擧，親親之意，謂何？徐俟其變，應之未晩。"**(국공이 분수를 넘어도 반역의 모습이 아직 드러나지 않았다. 짐이 먼저 치면 혈육을 아끼는 뜻은 어찌 되겠는가. 천천히 그가 움직이길 기다렸다 대응해도 늦지 않다) ✔ ★★
  - **1126.5 乙酉** 숭덕부 군사가 침전 쪽으로 오자 왕의 쪽지: **"今日，崇德府軍將持兵，至殿北，若將入寢門。朕若遇害，實否德所致。所可痛者，太祖剏業，列聖相繼，以至寡躬，若爲異姓所易，非獨朕罪，實輔相大臣，所深恥也。惟卿圗之。"**(오늘 숭덕부 군사가 무기를 들고 침전 북쪽에 와서 들어오려 한다. 짐이 해를 입는다면 내 덕이 모자란 탓이다. 아픈 것은 태조께서 세우고 대대로 이어 온 나라가 다른 성씨에게 넘어가는 것이니, 짐만의 죄가 아니라 대신들의 큰 부끄러움이다. 경이 꾀하라) ✔ ★ → 척준경이 울타리 나무를 몽둥이 삼아 들어와 왕을 군기감으로 모심 → 이자겸 "服素而至" → 팔관보에 가둠 ✔. 왕 "禍起蕭墻，大逆不道，賴忠臣義士，擧義除害" ✔
  - 5.丙戌 이자겸·처 최씨·아들들 유배(영광 등), 박표는 길에서 죽여 물에 던짐 ✔ / 12월 이자겸 영광에서 사망 ✔
  - 5.丁亥 선지: **"朕以幼冲，承襲祖業，意欲倚賴外家，事無大小，一切委任，而縱爲貪暴，殘民害國。朕雖知之，無以防閑。"**(짐은 어려서 나라를 이어 외가에 기대려고 크고 작은 일을 다 맡겼는데, 멋대로 탐하고 사나워 백성을 해치고 나라를 해쳤다. 짐은 알면서도 막을 길이 없었다) ✔ ★
- 6.乙卯 이자겸의 두 딸(왕비)을 내보냄. 간관 "宮主於上，爲從母，不可以配極" ✔. 넷째 딸에게는 "王念覆椀之功，賜田宅、奴婢，恩眷甚厚" ✔(권88). 대신 임원후(임원애)의 딸을 들임(→ 공예태후, 의종·명종·신종의 어머니) ✔

## 3. 남은 사람들 — 척준경, 그리고 용서 (1127~1145) — 권15·16·17, 권127
- **1127.3 乙卯 척준경 유배**: 정지상 상소 **"五月之事，一時之功也，二月之事，萬世之罪也。陛下雖有不忍人之心，豈以一時之功，掩萬世之罪乎？"**(5월 일은 한때의 공이고 2월 일은 만세의 죄입니다. 폐하께 차마 못 하는 마음이 있으셔도 한때의 공으로 만세의 죄를 덮겠습니까) → 암타도 ✔. 열전: "且知王忌俊京"(왕이 척준경을 꺼리는 것을 알고) ✔
- 1127.10 "刷諸李所奪土田臧獲，悉還本主"(이씨들이 빼앗은 땅과 노비를 다 주인에게 돌려줌) ✔
- 1129.3 척준경 처자에게 직전을 돌려줌 ✔

- **1146.2 사망**: 병중에 이자겸·척준경 탓 점괘, 무당 말로 **"決金堤郡新築碧骨池堰"**(김제 벽골지 둑을 터뜨림) ✔ — 흠. 유조: "聖哲之道，知其存亡，佛老之言，一乎生死，此盖事之必至，理之自然" ✔
- **김부식 찬**(고려 사신, 묘청 난을 진압하고 『인종실록』을 편찬한 당사자): **"仁宗自少，多才藝，曉音律，善晝畵。喜觀書，手不釋卷，或達朝不寐 … 性又儉約 … 專以德惠安民，不欲興兵生事。及金國暴興，排群議，上表稱臣 … 不幸資謙恣橫，變生宮闈，身遭幽辱，然以外祖之故，曲全其生，至如拓俊京，亦棄過錄功，俾保首領，斯可以見度量之寬矣 … 惜乎，惑妙淸遷都之說，馴致西人之叛，興師連年，僅乃克之，此其爲盛德之累也。"** ✔ ★ — 묘청을 '흠'으로 본 것은 김부식 자신의 입장이 들어감.
- **김신부 평**(고려 사신): **"睿廟末年，屬念房帷，馴致外家貪恣之行。仁宗幼冲卽位 … 又惑於凈心壽翰陰陽之說，卒致西都之叛逆者，何也？盖以天性，一於慈愛，優游不斷故耳。是以，典刑未正於丙午之逆類，處置不均於西都之叛民。又深信浮屠，增益生民之弊，惜哉！其不喜遊宴，減省宦寺，恭儉以飾身，誠信以交隣，雖古帝王，何以加焉。"**(타고난 성품이 오로지 자애로워 머뭇거리고 끊지 못했기 때문이다. 그래서 병오년 역적의 벌이 바르지 못했고 서경 반란민의 처리가 고르지 못했다 …) ✔ ★

## 축(제안)
- 인종 자신의 말 **"親親之恩，天性自然，每一念來，痛心切骨"**(1132.11) + **"朕若先擧，親親之意，謂何？"**(1126) + **"西人皆吾赤子 … 愼勿多殺"**(1135) + **"罪實在予"**(1135) → **"모질지 못한 왕 — 끊지 못했고, 그래서 늘 스스로를 탓한 왕"**.
  - 어머니를 아홉 살에 잃고 외가에서 자람("上生長外家" 김인존). 외할아버지를 '어머니의 넋'으로 높였고(1124), 쳐낼 때도 "反狀未著"를 기다렸으며, 죽은 뒤에도 추증·곡식. 묘청도 "雖持疑"하면서 끊지 못함 — 김신부 "一於慈愛，優游不斷".
  - 그러나 그 모질지 못함이 업적이 되기도: 금과 싸우지 않음("不欲興兵生事"), 송의 길 요구를 정중히 거절, 서경 진압에서 "愼勿多殺", 김부식에게 끝까지 맡김, 이자겸 집안 땅을 주인에게 돌려줌.
  - 「인종은 왜 그랬을까」: 열세 살에 할아버지 손에 올라 할아버지의 딸(이모) 둘과 혼인한 아이에게, 할아버지는 적이기 전에 어머니 쪽 유일한 핏줄이었을 것입니다(≈ 해석, 근거 1124·1132 제서 ✔).
- 흠: ① 1126.2 산호정 — 살려고 왕위를 넘기겠다는 글을 씀. ② 외조부를 몰아내려는 뜻이 비쳐 김찬 등이 먼저 움직였고, 그 밤 수많은 군사·근신이 죽음(김인존 말을 듣지 않은 결과 — 본인도 "恨不用金仁存之言"). ③ 이자겸의 딸(이모) 둘과 혼인을 "不得已" 받아들임. ④ 척준경 — 쓰고 버림(1127 유배, 열전 "王忌俊京"). ⑤ 묘청 — 의심하면서도 "以衆口力言，不得不信", 대화궁 공사로 "民死於役者頗衆", 처형 상소를 "不報". ⑥ 무당 금지를 뇌물 받은 권귀 말에 풀어 줌(1131). ⑦ 1135 항복하러 온 윤첨을 결국 하옥 → 재반란(처리 불균). ⑧ 병중 무당 말에 벽골지 둑을 터뜨림, 이자겸·척준경 '탈'을 믿음. ⑨ 김신부 "深信浮屠，增益生民之弊".

## 막 후보 (인종이 직접 고른 자리)
1. **1126 초 — 외할아버지의 권력을 빼앗을까**
   - 상황: 이자겸이 생일을 '절'이라 부르고 군국사를 맡겠다며 날짜까지 정함. 왕은 열일곱, 왕비 둘이 이자겸의 딸.
   - 다른 길 A: 김인존·이수 말대로 "請俟其閒" — 때를 기다린다. B: 이자겸에게 다 맡기고 이름만 왕으로 산다.
   - 실제: 몰래 물었다가 "王不聽" → 김찬·안보린이 "揣知王意" 하고 거사 → 실패, 궁궐 불탐 ✔. 왕이 직접 명령했다는 기사는 ✘ — '뜻이 비쳤다'까지만.
   - 말: 김인존·이수 **"上生長外家，恩不可絶。況彼黨與滿朝，不可輕動，請俟其閒。"** ✔
2. **1126.2 산호정의 밤 — 살아남을까, 자리를 지킬까**
   - 상황: 궁이 불타고 시종은 흩어지고 10여 명뿐. 화살이 왕 앞까지 날아옴.
   - 다른 길 A: 남은 사람과 끝까지 버틴다. B: 궁을 빠져나가 몸을 숨긴다.
   - 실제: **"王恐被害，作書，請禪位於資謙"** → 이수 "李公豈敢如是？" → 이자겸이 울며 돌려줌 ✔. 왕위를 내놓은 것이 오히려 목숨과 자리를 지킴(이자겸이 양부의 눈을 두려워함 "資謙畏兩府議").
   - 말: 이자겸 "臣無二心，惟聖鑑諒之" ✔ / 인종 "恨不用金仁存之言" ✔(inner 후렴 후보).
3. **1126.5 척준경이 "願自効" — 지금 칠까**
   - 상황: 독떡, 독약(넷째 딸 왕비가 막음). 척준경이 이자겸과 틀어짐.
   - 다른 길 A: 척준경을 믿지 말라(그 동생·아들이 2월에 관군에게 죽었다) — 혼자 버틴다. B: 곧바로 척준경에게 이자겸을 치라고 명한다.
   - 실제: **"國公雖僭亂，反狀未著。朕若先擧，親親之意，謂何？徐俟其變，應之未晩。"** → 숭덕부 군사가 침전 북쪽에 오자 그때 쪽지 "惟卿圗之" ✔. 먼저 치지 않고, 상대가 움직인 순간에 움직임.
   - 말: 최사전 "資謙所以跋扈者，惟恃拓俊京。若得俊京 … 資謙特一夫耳" ✔ / 인종 "俊京爲國公腹心 … 以是疑之" ✔.
4. **1129~1134 서경으로 갈까 — 칭제건원·금 정벌 (중심 사건)**
   - 상황: 개경 궁궐은 탔고, 묘청 "金國執贄自降，三十六國，皆爲臣妾". 정지상·대신들이 성인이라 연명.
   - 다른 길 A: 묘청 말대로 황제라 칭하고 서경으로 옮겨 금을 친다. B: 임원애 말대로 묘청을 저잣거리에서 처형한다.
   - 실제: 대화궁은 짓고 여러 번 가되, 칭제·금 정벌은 "王終不聽"·"不報", 처형 상소도 "不報" → 1134 김부식 "若是吉地，天必不如此" → **"所言至當，朕不西行"** ✔. (중간 길: 믿고 싶었으나 끝까지 다 믿지도, 끊지도 못함.)
   - 말: 묘청 ✔, 이지저 "金國强敵，不可輕也 … 不可偏聽一兩人之言" ✔, 재추 "人可欺，天不可欺也" ✔, 김부식 ✔.
5. **1135 서경이 반란했다 — 어떻게 칠까**
   - 상황: 대위국·천개. 조정에서는 "不計死傷，刻日破賊"(사상자를 따지지 말고 날짜를 정해 깨라)는 논의.
   - 다른 길 A: 군사를 몰아 단숨에 성을 깨뜨린다. B: 묘청 무리가 요구한 대로 서경으로 가서 달랜다("伏望，主上移御此都").
   - 실제: 김부식에게 "西人皆吾赤子 … 愼勿多殺", 자책 조서 "罪實在予", 1년 넘는 포위를 "卒排群議而委之" ✔. 대가: 1년 넘게 백성 동원("饋餉屬途而弗絶，衆庶勞止").
   - 말: 김부식 "不如好謀而成，何必疾戰，多殺人乎？" ✔ / 서경 표 "人心可畏，衆怒難防，車駕若臨，兵戈可戢" ✔.
- (보조) 1128 송의 '길 빌려 달라' 거절(신의 vs 생존, 1131 "其如信義何") — 4막 앞 짧은 장면 또는 deep. 『삼국사기』(1145)는 에필로그: 김부식에게 맡기고 "就第獎諭".
