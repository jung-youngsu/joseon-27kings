# 고려 태조 왕건(877~943, 재위 918~943) 『고려사』 조사 노트

원문: 위키문헌 『高麗史』 — 권1·2(세가 태조), 권88(열전 후비1), 권92(열전 홍유·배현경·유금필·최응·박술희·최지몽 등), 권93(최제안). 캐시: scratchpad/gr/ws/v001.txt …
표시: ✔ = 『고려사』 원문 확인 / ≈ = 『고려사』 밖(전승·학설) / ✘ = 『고려사』에서 찾지 못함
나이: 사건 연도 − 877(唐 乾符 4년 정월 출생, 권1). 896 열아홉, 909 서른둘, 913 서른여섯, 914 서른일곱, 918 마흔하나, 926 마흔아홉, 927 쉰, 930 쉰셋, 931 쉰넷, 935 쉰여덟, 936 쉰아홉, 943 예순여섯. 『고려사』 "時太祖年二十"(896)·"壽六十七"(943)은 세는나이.

## 1. 궁예의 장수 (896~914) — 권1
- 896 아버지 왕륭(세조)이 송악을 들어 궁예에게 귀부. "大王若欲王朝鮮、肅愼、卞韓之地，莫如先城松嶽，以吾長子爲其主。" → 발어참성을 쌓고 성주. "時太祖年二十" ✔
- 903 수군으로 금성 공격, 나주로 고침 ✔. 진언 "安邊拓境之策" ✔
- 906 궁예가 신라를 '멸도'라 부르고, 신라에서 온 사람을 다 죽임 ✔
- 909 나주 앞바다 견훤 수군과 대전. 제장이 걱정하자 **"勿憂也。師克在和，不在衆。"**(걱정 마라. 군대가 이기는 것은 화합에 달렸지 수에 달린 것이 아니다) ✔ / 김언 등이 공에 상이 없다고 불평하자 "今主上恣虐，多殺不辜，讒諛得志 … 莫如外事征伐，殫力勤王，以得全身之爲愈也"(지금 임금이 포학해 죄 없는 사람을 많이 죽이니 … 밖에서 싸우며 힘을 다하는 것이 몸을 온전히 하는 길) ✔ / 수달 능창 사로잡음 ✔
- 913 파진찬 겸 시중. **"然非素志，且畏讒，不樂居位 … 惟抑情謹愼，務得衆心，好賢嫉惡。每見人被讒，輒悉觧救。"**(본뜻이 아니었고 참소를 두려워해 자리를 즐기지 않았다 … 마음을 누르고 삼가 사람들의 마음을 얻는 데 힘썼다. 남이 참소를 당하면 늘 풀어 주었다) ✔ — 아지태 사건 → "太祖懼禍及，復求閫外" ✔
- 914 궁예 "我得彌勒觀心法" · 쇠방망이 ✔. **관심법 장면**: "卿昨夜，聚衆謀叛，何耶？" → 태조 "烏有是哉？" → 궁예 "我將入定以觀" → 장주 최응이 붓을 떨어뜨리고 지나가며 **"不服則危"**(자복하지 않으면 위험합니다) → 태조 **"臣實謀叛，罪當死"** → 궁예 "卿可謂直也" · 금은 안장 · "卿勿復誑我" ✔ (권92 최응전도 같음 "太祖悟，遂誣服，由是，得免" ✔)
- 914 나주로 다시. 남방 기근 "戍卒皆食半菽，太祖盡心救恤，賴以全活" ✔

## 2. 918 추대와 즉위 — 권1, 권88, 권92
- 918.3 왕창근의 거울 참문 ✔(설화적 기사, "전한다"로).
- 918.6 을묘 밤 홍유·배현경·신숭겸·복지겸 ✔. 권92 홍유전: 태조 **"吾以忠義自許，王雖暴亂，安敢有二心？以臣伐君，斯謂革命，予實不德，敢效湯、武之事乎？恐後世以爲口實。"**(나는 충의를 지키려 했다. 임금이 포악해도 어찌 두 마음을 품겠느냐. 신하가 임금을 치는 것을 혁명이라 하는데, 덕 없는 내가 탕왕·무왕을 흉내 내겠느냐. 뒷세상이 핑계로 삼을까 두렵다) / 장수들 "時難遭而易失。天與不取，反受其咎 … 公若不從，吾等死無日矣" ✔ / 권88 신혜왕후 유씨: 장수들이 "동산에 새 오이가 있겠지요, 따 오십시오"로 내보냈으나 장막 뒤에서 듣고 나와 **"擧義代虐，自古而然。今聞諸將議，妾猶奮發，况大丈夫乎？"** 갑옷을 입힘 ✔ / 새벽 곡식 더미 위에 앉아 군신의 예 ✔ / 궁예 "王公得之，吾事已矣" 북문으로 달아나 부양 백성에게 죽음 ✔
- 918.6 병진 포정전 즉위, 국호 고려, 천수 ✔. 정사 조서: 전주는 "以姦回爲至道，以威侮爲要術。徭煩賦重 …"(간사함을 바른 길로, 위엄과 업신여김을 다스림의 방법으로 삼았다) ✔
- **즉위 한 달의 칼**: 6.경신 마군장군 환선길 모역 처형 / 6.기사 마군대장군 이흔암 모반 기시(저잣거리 처형) / 9.을유 순군리 임춘길 등 모반 처형 / 10.신유 청주 수 진선·선장 형제 모반 처형 ✔. 궁예 때 아첨하던 종간·은부 처형(6.임술) ✔
- 6.무오 청주 사람 80여 명 풀어 줌("前主信讒好殺 … 俱以非辜") ✔
- **918.8 기유 "朕慮諸道寇賊聞朕初卽位，或構邊患。分遣單使，重幣卑辭，以示惠和之意。」歸附者果衆，獨甄萱不肯交聘。"**(여러 도의 도적들이 내가 막 즉위한 것을 듣고 변경에서 일을 꾸밀까 걱정이다. 사신을 나눠 보내 선물을 두텁게, 말을 낮추어 화친의 뜻을 보이라 — 과연 많이 따랐고, 견훤만 사귀지 않았다) ✔ ★
- 8.신해 궁예 때 굶주려 몸을 판 백성 천여 명을 왕실 창고 베로 되사 줌 ✔
- 8월 공신 포상 조서: **"朕與公等，欲救生民，未能終守臣節，以此爲功，豈無慚德？"**(짐과 공들은 백성을 구하려 했으나 끝내 신하의 절개를 지키지 못했으니, 이를 공으로 삼는 것이 어찌 부끄럽지 않겠는가) ✔ ★
- 9월 구진이 나주 부임 거절 → 엄벌 거론 → 구진이 사죄하고 감 ✔ / 서경(평양) 대도호부, 사촌 왕식렴 ✔
- 918.11 팔관회 시작 ✔

## 3. 견훤과의 26년 — 권1·2
- 925.10 조물군에서 견훤과 싸움 → 견훤이 화친 청함, 외조카 진호를 볼모. 태조도 사촌 왕신을 볼모. "以萱十年之長，稱爲尙父" ✔. 신라 "萱反復多詐，不可和親" ✔
- **926.4 경진** 진호 병사 → 견훤이 "우리가 죽였다" 하며 왕신을 죽이고 웅진으로 진격. "王命諸城，堅壁不出"(여러 성에 굳게 지키고 나가지 말라). 신라 사신 **"甄萱違盟擧兵，天必不祐。若大王奮一鼓之威，萱必自敗。"** / 태조 **"吾非畏萱，俟惡盈而自僵耳。"**(나는 견훤이 두려운 것이 아니다. 악이 가득 차 스스로 넘어지기를 기다릴 뿐이다) / 견훤이 '절영도 명마가 오면 백제가 망한다'는 참언을 듣고 말을 돌려 달라 하자 "王笑而許之" ✔ ★
- 927.1 "時甄萱違盟，屢擧兵侵邊，王含忍久之。萱益稔惡，頗欲强呑，故王伐之" → 용주 ✔ / 견훤이 왕신의 시신을 돌려보냄 ✔
- **927.9** 견훤이 신라 서울 습격, 포석정 → 경애왕 자결 강요, 왕비 욕보임, 김부(경순왕)를 세움 ✔. 태조 "大怒" → 정기 5천으로 공산 동수에서 맞섬, "大戰不利 … 大將申崇謙、金樂力戰死之，諸軍破北，王僅以身免" ✔. (신숭겸이 왕의 옷을 입고 대신 죽었다는 이야기는 『고려사』에 없음 ✘ — 후대 전승 ≈)
- 927.12 견훤 편지: "所期者，掛弓於平壤之樓，飮馬於浿江之水"(바라는 것은 평양 누각에 활을 걸고, 패강 물을 말에게 먹이는 것) ✔ / 928.1 태조 답서(긴 문장, 최언위 지은 것으로 알려짐 ≈) ✔
- 928.11 오어곡성 함락, 항복한 장군 6명의 처자를 제군 앞에서 기시 ✔ (흠)
- 929.7 의성 홍술 전사 "吾失左右手矣" ✔
- **930.1 고창(안동) 병산** 대승 "死者八千餘人" → 30여 군현, 동해안 110여 성 귀부 ✔
- 931.2 50여 기로 신라 방문, 임해전 잔치, 경순왕 울음 ✔ / 5월 돌아갈 때 백성 **"昔甄氏之來，如逢豺虎，今王公之來，如見父母。"** ✔
- 932.5 서경 '암탉이 수탉이 됨' 조서: "竊恐緣此，以致天譴" — 신하들이 공도를 행하지 않아 백성이 원망할까 ✔
- 934.5 예산진 조서: 녹읍 받은 권세가가 백성을 착취 — "予以一身，豈能家至而目覩？" / 백성 대신 하소연한 자 소환에 안 오면 매 열 대 ✔
- 934.7 발해 세자 대광현 수만 명, 왕계라는 성명, 종적에 ✔
- 935.3 신검이 견훤을 금산사에 가둠 → 6월 견훤 나주로 탈출해 투항, 다시 상보, 양주 식읍 ✔

## 4. 935 신라의 귀부 — 권2, 권88
- 935.10 경순왕 김부 입조 청함 → 11월 30리 행렬, 유화궁, 맏딸 낙랑공주를 시집보냄 ✔
- 11.기미 경순왕 **"本國久經危亂，曆數已窮，無復望保基業，願以臣禮見。"** → "不允" ✔
- 12.신유 군신 **"天無二日，土無二王，一國二君，民何以堪？願聽羅王之請。"** ✔
- 12.임신 천덕전 **"朕與新羅，歃血同盟，庶幾兩國永好，各保社稷。今羅王固請稱臣，卿等亦以爲可，朕心雖愧，衆意難違。"**(짐은 신라와 피를 마시며 맹세해 두 나라가 길이 사이좋게 각자 나라를 지키기를 바랐다. 이제 신라 왕이 굳이 신하가 되겠다 하고 경들도 옳다 하니, 짐의 마음은 부끄러우나 여러 사람의 뜻을 어기기 어렵다) → 정승, 태자 위, 녹 천 석, 신란궁, 따라온 사람 녹용, 신라를 경주로 고쳐 식읍 ✔ ★
- 권88 신성왕후 김씨: 태조 "今王以國與寡人，其爲賜大矣。願結昏宗室，以永甥舅之好。" → 경순왕의 큰아버지 억렴의 딸 → 안종(현종의 아버지) ✔
- 937.5 신라 성제대(옥대) ✔

## 6. 만년 — 권2
- 940 신흥사 공신당, 삼한공신을 벽에 그림 ✔
- **942.10 만부교** — 거란이 낙타 50필 → "契丹嘗與渤海連和，忽生疑貳，背盟殄滅，此甚無道" → 사신 30명 섬으로 귀양, 낙타는 만부교 아래 매어 굶겨 죽임 ✔ (흠/논쟁 — 뒤의 거란 침입은 성종·현종편)
- **943.4 훈요 10조**(박술희에게 친히 줌) ✔: 서문 "朕亦起自單平，謬膺推戴 … 第恐後嗣縱情肆欲，敗亂綱紀" / 1 불교 / 2 도선 / **3 "若元子不肖，與其次子 …"** / 4 거란 "禽獸之國" / 5 서경 / 6 연등·팔관 / **7 "人君得臣民之心爲甚難。欲得其心，要在從諫、遠讒而已。"**(임금이 신하와 백성의 마음을 얻는 것은 매우 어렵다. 그 마음을 얻으려면 간언을 따르고 참소를 멀리하는 데 있을 뿐이다) / "使民以時，輕徭薄賦，知稼穡之艱難，則自得民心" ★ / **8 "車峴以南，公州江外 … 雖其良民，不宜使在位用事"**(차현 남쪽 공주강 밖 … 양민이라도 벼슬에 두지 말라) ✔ — 흠 / 9 녹봉·병졸 / 10 경사
  - 훈요의 전래: 권93 최제안전 **"初太祖信書訓要，失於兵燹，齊顔得於崔沆家，藏以進，由是，得傳于世。"**(병화로 잃었다가 최제안이 최항의 집에서 얻어 바쳐 세상에 전해졌다) ✔ → 8조 등이 뒤에 고쳐졌다는 학설(이병도 위작설 ≈)과 그 반론(≈)
- **943.5** 병석 "漢文之言卽予意也" / 유조 / 곡소리에 "此何聲也" → **"浮生自古然矣。"**(뜬 인생은 예부터 그러한 것이다) 웃으며 세상 떠남 ✔ / "喪葬園陵制度 … 悉從儉約" ✔ / 사신 평 "規模宏遠，正朝廷，明賞罰。崇節儉，用賢良，重儒道" ✔
- 이제현 찬: 충선왕 말 "以不世之功，處必疑之地，可謂危矣 … 然猶固讓 … 好生惡殺，而信賞必罰，推誠功臣，而不假以權" ✔

## 7. 혼인 — 권88 후비전
- 태조의 후비 29명(신혜왕후 유씨 ~ 해량원부인) ✔ 표제 수.
- 장화왕후 오씨(나주): 혜종의 어머니. "以側微，不欲有娠" 설화 ✔(설화, 쓰지 않음). 혜종 7살 때 "恐母微不得嗣位" → 자황포 상자 → 박술희가 알아 정윤으로 ✔ → 혜종편으로.
- 후비전 서문(조선 편찬자): "太祖法古，有志化俗，然狃於土習，以子聘女，諱稱外姓 … 惜哉" ✔ — 왕실 근친혼을 조선이 비판.
- 유금필전 태조 **"凡爲將，貴得人心。"** ✔(권92)
