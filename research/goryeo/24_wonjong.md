# 고려 원종 왕식(1219~1274, 재위 1259/1260~1274) 『고려사』 조사 노트

원문: 위키문헌 『高麗史』 — 권24 끝(세가 고종 45·46년, v024), 권25~27(세가 원종1~3, v025~v027), 권81(병지1 삼별초, v081), 권88(후비1 안혜태후·순경태후·경창궁주, v088), 권89(후비2 제국대장공주, v089), 권91(종실 안경공 창·순안공 종, v091), 권102(이장용, v102), 권104(김방경, v104), 권123(폐행 강윤소·이분희, v123), 권130(반역4 홍복원·김준·임연·임유무·조이·우정·최탄·배중손, v130). 캐시: scratchpad/gr/ws/vNNN.txt
표시: ✔ = 『고려사』 원문 확인 / ≈ = 『고려사』 밖(전승·학설) / ✘ = 『고려사』에서 찾지 못함
이름: 휘 식(禃 — 위키문헌은 𫌁/⿰衤直로 적음), 자 일신(日新), 옛 휘 전(倎). "王改名禃"은 1260.6(권25) ✔. 고종의 맏아들, 어머니 안혜태후 유씨(희종의 딸) ✔(권25 총서, 권88).
나이: 사건 연도 − 1219(고종 6년 기묘 3월 을유 출생, 권25). 1235 열여섯(태자 책봉), 1259 마흔(몽골 입조·고종 죽음), 1260 마흔하나(즉위), 1264 마흔다섯(친조), 1268 마흔아홉(김준 제거), 1269 쉰(폐위·복위), 1270 쉰하나(개경 환도·삼별초), 1271 쉰둘, 1273 쉰넷(탐라 평정), 1274 쉰다섯(세자 혼인·죽음). 『고려사』 "壽五十六"(1274)은 세는나이.
- 쿠빌라이(원 세조)는 1215년생 ≈(『원사』, 『고려사』에 생년 없음) → 1259 마흔넷.
- 아들 충렬왕 왕심(諶) 1236년생 → 1259 스물셋, 1269 서른셋, 1274 서른여덟. 이복동생 안경공 창(淐, 생년 ✘).

용어·편찬 메모
- 1259~1271 『고려사』는 상대를 '蒙古'로 적다가 1271.12 "蒙古遣使，告建國號曰大元"(권27) 뒤부터 '元'으로 적는다 ✔. 게임에서도 1271년 전은 '몽골'로.
- 묘호 '원종(元宗)'·시호 '순효(順孝)'는 고려 신하들이 올린 것("百官上謚曰順孝，廟號元宗", 1274.6 갑자, 권27) ✔. 원이 내린 시호는 '충경(忠敬)' — "忠宣王二年七月乙未，元贈謚忠敬"(권27) ✔. **원종은 고려식 묘호(○종)를 가진 마지막 왕**이고, 다음 충렬왕부터 왕호가 원이 내린 '충○왕'이 된다(그래서 원종은 '충경왕'이라 부르지 않는다).
- 원종 세가는 아직 왕이 "朕", 명령을 "制"·"宣旨"·"詔" 식으로 적는다(1264.7 "制曰：「朕以凉德…」", 1264.7 "宣旨曰", 1271.10 "赦曰：「朕以凉德…」", 1274.6 遺詔 "朕以凉德") ✔. 칭호를 낮춰 적는 것은 충렬왕 때 일(그 노트 참고) — 원종 세가에서 낮춘 사례 ✘.
- 아들 왕심의 호칭: 1260 "子諶爲太子"(태자) → 몽골 문서·1269 이후 세가는 "世子諶" ✔. 원 쪽 눈으로 '제후의 아들'이 된 것.
- 몽골 쪽 말이 백화(구어)라 문장이 어색한 곳이 있다(1260.8 속리대 편지 "島子裏坐底，伱識者 …") ✔ — 직역하지 말고 풀어 쓸 것.
- 조선 편찬자의 사신 찬(1274, 권27)은 "使東方之民，享百年昇平之樂"이라고 원과의 혼인을 칭찬하면서, 동시에 "溺於宴安"이라 깎는다 — **누가 쓴 평인지 밝혀 옮길 것.**

## 1. 태자 시절 (1235~1258) — 권24·25·88
- 1235.1 태자 책봉 "二十二年正月，冊爲太子"(권25 총서) ✔ — 열여섯.
- 같은 해 비 김씨(순경태후) — "慶州人，莊翼公若先之女 … 高宗二十二年，元宗爲太子，納爲妃，生忠烈王而薨"(권88) ✔. 김약선은 최우의 사위(최우 가문 쪽 사실은 권129 최이전 참고 — 고종 노트). 그래서 뒤에 경창궁주가 충렬을 "權臣之甥"이라 부름(아래 4절).
- 몽골이 해마다 "王太子親朝"를 요구 — 1256.4 "若國王出迎使者，王太子親朝帝所，兵可罷還"(권24) ✔.
- 1258.6 병신 차라대 사자 "今國王及太子出降西京，則便可回兵" → 고종 **"予旣老病，不可遠行。"** ✔ / 1258.7 여수달 "太子如欲見我，期於猫串江邊" → 재추가 "太子有疾，待疾愈往見" ✔ / 1258.8 기해 사자 "太子出則，兵可退矣" → 고종 **"太子有病，豈能出哉？"**(태자가 병이 있는데 어찌 나가겠느냐) ✔ — 아버지가 아들을 내보내지 않으려 버팀(병은 핑계였을 가능성 ≈).
- 1258.3 병자 유경·김인준(김준)이 최의를 죽이고 "復政于王" ✔(고종편).
- 1258.12 갑진 박희실 등 몽골에: "本國所以未盡事大之誠，徒以權臣擅政，不樂內屬故爾 … 譬之穴鼠，爲猫所守，不敢出耳。"(권신 때문이었다. … 구멍 속 쥐가 고양이에게 지켜져 나오지 못하는 것과 같다) ✔

## 2. 1259 쿠빌라이를 만나다 — 권24·25
- 1259.3 계축 온양가대가 입조 시기를 묻자 고종 "五月" → "若待五月，何其晩也" → 4월로 약속 ✔ / 병자 "太子出宴客使于重房，期以四月二十七日" ✔.
- **1259.4 갑오 "遣太子倎奉表，如蒙古。參知政事李世材，樞密院副使金寶鼎等四十人從之"** ✔ — 비용: "文武四品以上出銀各一斤 … 國贐䭾馬三百餘匹，以馬不足，抑買路人馬，以故，兩班乘馬者少"(말이 모자라 길 가는 사람의 말을 억지로 사들였다) ✔ 표문(고종 이름): "嗟，小臣老病旣深 … 肆今日不得親朝，令太子姑且往覲" ✔. 마흔.
- 1259.6 경진 이세재 보고: 5.16 호천에서 큰물 — **"從者皆請留宿，以待水落，太子不聽遂行"**(따르는 이들이 물이 빠질 때까지 묵자고 했으나 태자는 듣지 않고 갔다) ✔ / 동경에서 "明日，大兵將向高麗" ✔ / 5.19 송길대왕 "皇帝親征宋國，委吾等征爾國，業已發兵，爾何來耶？" → 태자 "我國惟皇帝及大王之德是賴 …" / 송길 "王京猶在島中，何可罷兵？" → 태자 **"大王嘗言，太子入朝，則罷兵，故今我來爾。兵若不罷，小民畏懼逃竄，後雖敦諭，誰復聽從，大王之言，其可信乎？"**(대왕께서 태자가 들어오면 군대를 물린다고 하셨기에 왔습니다. 군대를 안 물리면 백성이 겁나 달아날 것이고, 뒤에 아무리 타일러도 누가 따르겠습니까. 대왕의 말을 믿을 수 있겠습니까?) → "松吉等然之，駐兵不發" ✔ ★ (대신 강도 성을 헐라는 사자를 보냄 → 1259.6 계미~경인 강화 내성·외성 헐기, "若知如此，不如不城" ✔)
- 권130 우정전: 반역자 우정·김수제가 "高麗有急，必遷濟州，今言復都舊京，非實" → 야속달이 대질시키려 하자 태자 **"何信叛人之言？吾寧祝髮被拘於此，豈可與叛人辨哉？"**(어찌 반역자의 말을 믿습니까. 차라리 머리를 깎고 여기 갇힐지언정 반역자와 말다툼하겠습니까) → "也速達愧而遣還" ✔
- 1259.6 임인 고종 죽음(유경 집) ✔. **"大將軍金仁俊欲奉安慶公嗣位，兩府議曰：「元子繼体，古今之通義也，况今太子，代王入朝，而以弟爲君，可乎？」"**(김인준은 안경공을 세우려 했으나 양부가 "맏아들이 잇는 것이 옳다. 더구나 태자가 왕 대신 입조했는데 동생을 왕으로 삼을 수 있겠는가") ✔ — 김준과의 첫 틈. 유조 "嗣王奉使未還閒，軍國庶務，聽於太孫" ✔ → 태손(왕심, 스물셋)이 감국.
- **헌종(몽케) 죽음과 갈림길** (1260.3 정해 기사 안의 회고, 권25): "初，憲宗皇帝南征，駐蹕釣魚山，王自燕京，赴行在，道過京兆、潼關" — 화청궁 온천을 권하자 **"此唐明皇，所嘗御者，雖異世，人臣安敢褻乎？"**(당 현종이 쓰던 것이니, 세상이 달라도 신하가 어찌 함부로 쓰겠는가) "聞者嘆其知禮" ✔ / **"至六槃山，憲宗皇帝晏駕，而阿里孛哥阻兵朔野，諸侯虞疑，罔知所從。時，皇弟忽必烈觀兵江南，王遂南轅閒關，至梁楚之郊"**(육반산에 이르니 헌종이 죽고, 아릭부케가 북쪽 들판에서 군대를 막고 있어 제후들이 누구를 따를지 몰랐다. 쿠빌라이가 강남에 있었으므로 왕은 수레를 남쪽으로 돌려 험한 길을 지나 양·초 들판에 이르렀다) ✔ ★ / 쿠빌라이는 양양에서 군대를 돌려 북상 중 — "王服軟角烏紗幞頭，廣袖紫羅袍，犀鞓象笏，奉幣迎謁道左。眉目如畵，周旋可則" ✔ / **쿠빌라이 "高麗萬里之國，自唐太宗親征而不能服，今其世子，自來歸我，此天意也。"**(고려는 만 리 나라라 당 태종이 몸소 쳐도 굴복시키지 못했는데, 이제 그 세자가 스스로 내게 왔으니 하늘의 뜻이다) "大加褒奬，與俱至開平府" ✔ ★
  - 조양필의 계산: "高麗雖名小國，依阻山海，國家用兵二十餘年，尙未臣附 … 誠能立倎爲王，遣送還國，必感恩戴德，願修臣職。**是不勞一卒，而得一國也。**"(군사 하나 쓰지 않고 나라 하나를 얻는 것이다) — 쿠빌라이도 셈을 했다 ✔. 염희헌도 같은 말 ✔.
  - 사신 찬(1274): "阿里孛哥，以憲宗嫡子，阻兵上都，世皇以藩王，在梁楚之郊，而乃能識天命民心之去就，**舍近之遠**"(가까운 쪽을 버리고 먼 쪽으로 갔다) ✔ — 조선 편찬자의 평.
  - '아릭부케 대신 쿠빌라이를 고른 이유'를 원종 자신이 말한 기록은 ✘. 정황(쿠빌라이가 가까이 남쪽에 있었다, 몽케의 군영이 흩어졌다)으로만 풀 것 — "…였을 것입니다".
- 1260.2 임술 **"王在京兆府聞訃，服喪三日而除，受忽必烈大王之命，乃還"**(경조부에서 아버지의 부고를 듣고 사흘 상복을 입고 벗었다) ✔ — 아버지의 죽음을 남의 나라 길 위에서.

## 3. 즉위와 '출륙'의 약속 (1260~1263) — 권25
- 1260.2 야속달 "三月上旬，皆出古京，金仁俊當率百官，迎于西京" → 왕 **"我國多賊而國無主，仁俊不可離京。"** ✔ — 김준을 지켜 줌.
- 1260.3 갑신 속리대(다루가치)를 시험: 먼저 승천궐에 들어가자 속리대 "彼此意異" 하며 떠나려 함 → 태손이 앵무잔·백은 30근을 줘 달램 ✔ / 3월 을미 속리대 **"館待日厚，感則感矣，然忽必烈大王，所以遣我者，非爲在島中，徒哺啜也，如之何？」王無以對。"**(대접이 날로 후해 고맙지만, 대왕이 나를 보낸 것은 섬에서 먹고 마시라고가 아니다) ✔ → 문무를 세 번으로 나눠 개경을 오가게 해 "以示遷都之意"(옮기는 시늉) ✔.
- 1260.4 병오 쿠빌라이(아직 즉위 전 이름) 글: "世子其趣裝命駕，歸國立政 … 出彼滄溟，宅玆平壤 … **於戲，世子其王矣**，往欽哉 … 永爲東藩" ✔ / 원종의 진정표: "詔云：『未臣服者，唯爾國與宋耳。』其謂宋不服者哿矣，顧如小邦，恒事大國，豈於此綂一之際，而敢懷携貳之心？" ✔
- **1260.4 무오 강안전(강화) 즉위** ✔ — 마흔하나. "灌頂，受菩薩戒于慶寧殿 … 後著黃衣，坐龍床南面，束里大、波透上殿，據床東面"(다루가치가 전각에 올라 동쪽에 앉음) ✔.
- 1260.4 신유 쿠빌라이 조서: "出水就陸，以便民居事，此朕所喜也 … 請罷軍士事 … 已勑將帥，卽日班師" ✔ / 1260.8 "**衣冠從本國之俗，皆不改易** … 古京之遷，遲速量力。屯戍之撤，秋以爲期" ✔ ★ — 이른바 '세조 구제(舊制)'의 근거가 되는 약속(이 명칭은 ≈ 학계 용어).
- 1260.6 속리대 김보정에게 **"爾王之東還也，奏帝曰：『臣之國，卽還都松京。』今已踰數月，何其恬不爲慮？爾等有幾頭乎？吾惟一頭，是以爲恐。"**(너희 왕이 돌아가며 곧 송경으로 돌아간다고 황제께 아뢰었는데 몇 달이 지나도 걱정도 않는구나. 너희는 머리가 몇 개냐. 나는 하나뿐이라 두렵다) ✔ — 원종의 약속이 다루가치의 목을 건 약속이 됨.
- 1260.6 정유 사면, 위사공신 순위를 바꿔 "以第一柳璥爲第五，金仁俊爲第一" ✔ — 김준에게 기댐.
- 1260.6 무신 이응 귀양: 연경에서 영녕공 준에게 "公若欲爲王，誰曰不可？" ✔ — 원종이 없는 사이 왕 자리를 노린 말이 있었다.
- 1260.7 속리대가 떠나려 하자 "王請留甚切"(간절히 붙잡음) ✔ — 몽골인을 곁에 두려 함(권신 견제용이었을 것 ≈).
- **1260.12 "是年，封冊四，嘉禮二，所費金銀千餘斤，米穀三千餘石，布帛不可勝計。" / "王聚宮女于水房，滛縱無節，御史大夫金仁俊，移置水房于外。"**(궁녀를 수방에 모아 절제 없이 놀자 김인준이 수방을 밖으로 옮겼다) ✔ — 흠.
- 1260.11 "設八關會 … 當國恤，奏還宮樂，識者譏之" ✔ / 1260.10 송 상인 비단 6천여 필을 대부시·내시원이 값 없이 빼앗음, "仁俊等不能禁" ✔.
- 1261.3 경오 안찰사들에게 **"朕欲推仁心，施及禽獸。方春田獵，恐其不麛不卵，違我好生之心。卿等體此，勿獻肉膳。"**(봄 사냥에 새끼와 알까지 해칠까 걱정이니 고기 반찬을 바치지 말라) ✔

## 6. 연경 — 혼인과 군대를 청하다 (1270.1~2) — 권26·102
- 1270.1 신해 동경 행성: 두련가·조평장이 사람을 물리고 붓을 주며 폐립 까닭을 몰래 쓰라 함 → **"王辭以手病風不書，乃使譯者問王。王順衍意答云：「如表所奏。」行省知其非實，不復問。"**(손에 풍이 왔다며 쓰지 않고, 통역이 묻자 임연 뜻대로 "표에 아뢴 대로"라고 답했다 — 행성은 거짓인 줄 알고 더 묻지 않았다) ✔ ★ / 권102: "行省問廢立之故，王以有疾遜位對。行省知其非實，請以藏用從行，**王惡藏用言與己異故，不許**"(이장용의 말이 자기와 다를까 싫어해 데려가지 않았다) ✔ — 흠/수수께끼: 왜 임연을 감쌌나. 임연 아들 임유간이 곁에 있었다(1270.4 두련가 "堅守林惟幹否？" → 왕 "何敢小懈？" ✔) — 귀국 전이라 두려웠을 것 ≈.
- 1270.1 신축(초하루) 박주에서 몽골 도당에 보낸 글: "安有國君，躬進帝所，而兵入其境，百姓驚動者乎？"(왕이 몸소 황제께 가는데 군대가 그 나라에 들어가 백성을 놀라게 하는 법이 있습니까) ✔.
- **1270.2 갑술 도당에 청혼**: "夫小邦請婚大朝，是爲永好之緣，然恐僭越，久不陳請 … **伏望許降公主於世子，克成合巹之禮，則小邦萬世永倚供職惟謹**"(공주를 세자에게 내려 주시면 우리나라는 만세토록 길이 기대어 삼가 섬기겠습니다) ✔ ★ / 같은 날 청병: **"伏望，許以兵若干人，與之俱往，直至舊京，招諭水內臣民，盡令出居，因除權臣，餘皆存撫"**(군사를 조금 빌려 함께 옛 서울로 가서 섬 안 신민을 다 나오게 하고, 그 김에 권신을 없애겠다) ✔ ★
  - 쿠빌라이의 답: "其請軍馬，許令發送，若請婚則聖旨云：『達旦法，通媒合族，眞實交親，敢不許之？**然今因他事來請，似乎欲速**，待其還國，撫存百姓，特遣使來請，然後許之。 …"(다른 일 때문에 청하니 서두르는 듯하다. 돌아가 백성을 돌본 뒤 다시 청하면 허락하겠다) ✔
- 1270.2 정축 최탄의 땅을 원에 붙여 **동녕부, 자비령을 경계** ✔ / 경진 원종 "伏望，許還諸城，俾屬本國" · 대군이 오면 "恐百姓驚竄，抑供億難支也。請停後軍，且大軍留屯古京，毋令越境" → "帝許請達魯花赤及兵不越境事，餘皆不允" ✔.
- 1270.2 을미 **임연 "憂懣，疽發背而死"** → 아들 임유무가 교정별감 ✔.

- 1270.5 임술 "宰樞會議復都舊京，榜示畫日，**三別抄有異心不從，擅發府庫**" / 병인 "王還舊京，御沙坂宮" / **무진 "遣將軍金之氐入江華，罷三別抄"** ✔ ★ / 병지(권81): "及王復都舊京，三別抄反懷疑二，故罷之" · 배중손전 "取其名籍還，三別抄恐以名籍聞于蒙古，益懷反心" ✔.
  - 삼별초의 기원(권81): "初，崔瑀憂國中多盜，聚勇士，每夜巡行禁暴，因名夜別抄 … 又以國人，自蒙古逃還者，爲一部，號神義，是爲三別抄。權臣執柄，以爲爪牙 … 金浚之誅崔竩，林衍之誅金浚，松禮之誅惟茂，皆籍其力" ✔ — 원종 자신도 김준·임유무 제거에 이 칼을 썼다.
- **1270.6 기사 배중손·노영희 "領三別抄叛，逼承化侯溫爲王"** ✔ / 배중손전: "蒙古兵大至，殺戮人民，凡欲輔國者，皆會毬庭！" · "凡兩班在舟不下者，悉斬之！" · 배 "千餘艘" 남하 · "時百官咸出迎王，其妻孥皆爲賊所掠，痛哭聲振天地" ✔ — 쉰하나.
- 1270.6 계유 두련가 군이 강화에 들어감 → **"王恐朶刺歹以遺民爲逆黨而殺掠，請勿入，朶刺歹不聽遂入，縱兵收掠財物"** ✔ / 을해 "時初出古京，衣冠未備，王及百官，皆以戎服行，又無官廨，皆張幕以居" ✔ / 1270.8 무인 "頭輦哥使人，焚江華城內民家" ✔.
- 1270.8 병술 삼별초 진도 ✔ / 9월 신사전 "我已爲宰相，破賊成功，復何爲哉？" ✔ / 김방경 토벌(권104) ✔.
- 1270.12 쿠빌라이 조서: "卿亦聽小人之言，寧非顯然？ … **卿國雖小，卿亦是一國之王，黜陟威福，或是或非，當自己出** … 若輩小人，於卿猶擅廢立，况於卿子孫，豈肯盡心輔佐？"(경의 나라가 작아도 경 역시 한 나라의 왕이니 상벌은 스스로 정해야 한다) ✔ — 원종이 몰래 송 상선을 돌려보낸 일도 꾸짖음.

## 8. 진도·탐라와 '황제의 백성' (1271~1273) — 권27·104
- 1271.1 이장용·최영을 폐립 공모로 면직 — "其首謀廢立事，侍中李藏用，叅知政事崔瑛，已皆黜職"(쿠빌라이에게 보고) ✔ / 권102 이장용 **"當時不能死，豈非罪乎？"** ✔.
- 1271.1 홍다구 "見王不拜" ✔ / 홍복원전: 홍다구가 숭겸 사건을 고려 조정에 엮어 "因起兵襲取京城" 하려 했으나 다루가치 탈타아가 막음 ✔.
- 1271.2 계묘 녹과전 / **"自權臣誅夷，諸王及寵臣李玄原、康允紹、李汾禧、金自貞、李汾成等，爭先請王，受其田園，至是，宰樞又請收之 … 王大怒，欲罪先發言者"**(권신의 땅을 왕족과 총신들이 앞다퉈 받았는데, 재추가 거두자 하니 왕이 크게 노해 처음 말한 사람을 벌하려 했다) ✔ — 흠.
- 1271.2 정미 "王親問民閒疾苦" ✔ / 무신 연등 날 300여 호 불 → 기악을 그만둠 ✔.
- 1271.3 둔전 — "屯田牛六千頭 … 餘三千頭，令經略司，受直王國和市" ✔ → 원종 표(1271.4): **"噫此百姓，皆是皇帝之百姓，迺此農牛、農器、種子，一皆收奪，使失其業，則恐百姓決定飢死 … 焉知愚民有所貳於彼哉？"**(아, 이 백성은 모두 황제의 백성입니다. 소·농기구·씨앗을 다 빼앗아 생업을 잃게 하면 백성은 틀림없이 굶어 죽을 것이고 … 어리석은 백성이 저쪽(삼별초)에 마음을 줄지 어찌 알겠습니까) ✔ ★ / 쿠빌라이(1271.6): **"卿一國臣民之主，敷奏不實可乎？爾後愼勿如此。"**(경은 한 나라 신민의 주인인데 아뢰는 것이 거짓이어서야 되겠는가) — 앞서 "限以力盡，不令受飢"라 해 놓고 못 한다고 했다며 ✔.
- 1271.3 쿠빌라이 "叛人未靖，王不可來朝" → 친조 비용으로 거둔 은·베를 돌려줌 ✔.
- 1271.5 정축 김방경·흔도·홍다구 진도 함락, 승화후 온을 벰, 김통정 탐라로 ✔ / 조양필 "其於亂離，不墜文風如此，良可嘉也" ✔.
- 1271.6 기해 **세자를 볼모로** — "先遣世子與衣冠胤冑二十人，衙內職員百人進詣" ✔.
- 1271.8 포로가 된 백성을 돌려 달라는 글: "雨露之澤，始優渥而今也漸希，籠檻之囚，初懽呼而卒乃啜泣" ✔ / 진정표: 김방경 보고 "界內百姓，皆食草實木葉" · 말 1만8천 필 군량 계산 ✔.
- 1271.10 사면(朕): 삼별초에 따라갔다 돌아온 이는 "亦各勿問，俾安其業" ✔ / 다루가치 탈타아의 죽음 "若飮此而死，則讒構爾國者，必曰高麗毒之" — "王亦甚重之" ✔.
- 1271.10 신축 "帝許世子婚" ✔ / 1271.12 "告建國號曰大元" ✔.
- 1272.2 세자 귀국 — "國人見世子辮髮、胡服，皆歎息，至有泣者" ✔(충렬왕 노트와 겹침).
- 1272.4 정사 원에 낸 표에 숫자: 경오(1270)~1272.4 "軍粮十萬九千一百九十九碩六，馬牛料四十三萬二千五碩六 … 種子一萬五千碩" ✔ — 이 숫자는 원종 정부가 원에 보고한 숫자임을 밝혀 쓸 것.
- 1272.5 탐라 초유사 금훈에게 삼별초 김희취 등: "爾等嘗遣人珍島，誘我綬其心，引大軍攻破。惟是父母妻子，人情最愛重，悉已驅掠而去，玆乃我輩怨入骨髓者也" ✔ — 삼별초 쪽 목소리(직접 대사로 쓸 수 있는 몇 안 되는 말).
- 1272.7 갑자 조자일이 왜선을 몰래 돌려보냄 → 홍다구가 국문, 1272.10 기해 **"洪茶丘殺曹子一"** ✔ — 원종이 지키지 못한 신하.
- 1273.2 신해 다루가치 이익이 좌창 녹봉을 막자 **"左倉陪臣俸祿所在，非官人所知，吾將奏于帝。」益乃止"** ✔ / 경자 "內莊宅告匱，闕御飯米一夕"(왕의 저녁밥 쌀이 떨어짐) ✔.
- 1273.4 경술 탐라 평정 — "其元住耽羅者，按堵如故" ✔ / 원이 탐라에 다루가치 ✔. 쉰넷.
- 1273.3 을해 조양필이 이익의 선물을 거절 "此汝侵割高麗而得也" ✔.
- 1273.10 신미 전지: 탐라 원정 때 달아난 별초의 "所收田丁，悉令還之" ✔.

## 9. 마지막 해 — 배와 여자들 (1274) — 권27·104
- 1274.1 전함 300척, 홍다구 감독 "催督甚嚴" — "徵集工匠、役徒三萬五百餘名 … 期限急迫，疾如雷電，民甚苦之" ✔ / 김방경이 "用本國船樣督造"(권104) ✔.
- 1274.3 **"王患徭役之煩，轉輸之弊，有防農務，遣上將軍李汾禧，往說茶丘，請令分半歸農"** → "每一船，留雙丁五十人，其餘單丁，悉放歸農" ✔.
- **1274.3 임인 만자 매빙사 — "令選無夫婦女一百四十名 … 置結昏都監 … 窮搜閭井獨女、逆賊之妻、僧人之女，僅盈其數，怨咨大興 … 哭聲震天，觀者莫不悽唏"** ✔ — 원종 재위 마지막 해의 일(흠·시대의 아픔).
- 1274.5 병술 **"世子諶尙帝女忽都魯揭里迷失公主"** ✔(권89 제국대장공주). 쉰다섯.
- 1274.6 원에 "船大小幷九百隻造訖" ✔.
- **1274.6 계해 제상궁에서 죽음** — 유조: "朕以凉德，叨守宗祧，十有五年 … 惟予元子 … 今在上朝，未獲親命 … 山陵制度，務從儉約 … **無以死傷生，一乃心力，保定邦家**"(죽은 사람 때문에 산 사람을 상하게 하지 말고 마음과 힘을 하나로 모아 나라를 지켜라) ✔ / 원에 유표 "世子諶，孝謹可付後事" ✔. 아들은 원에 있어 임종을 보지 못함 — 아버지 고종이 죽을 때 자신이 몽골에 있었던 것과 같은 모양 ✔(정황).

## 10. 평 — 권27
- **사신 찬(조선 편찬자)**: "元宗之爲世子也，權臣專權，恣行不義，畏上國討罪，不樂內附 … 王承父王之命，親朝上國，摧伏權臣跋扈之志，遂使疽背而死 … 舍近之遠，世皇嘉之，至以公主，歸于王子。自是，世結舅甥之好，使東方之民，享百年昇平之樂，亦可尙也。**但其三別抄內叛，侵掠州郡，元遣將帥，求索無已。是宜宵旰圖治之日也，顧乃溺於宴安，以致媵嬙蠱其心志，閹人專其出納，惜哉。**"(삼별초가 일어나고 원의 요구가 끝없던 때는 밤낮으로 다스림에 힘쓸 때인데, 도리어 편안함에 빠져 후궁들이 마음을 흐리고 환관이 왕명의 출납을 쥐었으니 아깝다) ✔
- 이제현 찬(원종) — 권27에 ✘(고종에는 있음).
- 세가에 불교 도량·초제 기사가 매달 거듭 나옴(소재도량·인왕도량·보살계 …) ✔ — 사신 찬의 '편안함에 빠졌다'와 함께, 할 수 있는 일이 적었던 왕의 기도로도 읽힘 ≈.

## 축(제안)
- 후보 A — **"대왕의 말을 믿을 수 있겠습니까"**(1259, 송길대왕에게). 칼(군대)이 없던 왕이 가진 무기는 **말과 약속**이었다. 상대에게 약속을 지키라고 따졌고(1259 송길, 1270.1 "安有國君 …"), 자신은 약속으로 시간을 벌었다(1260 출륙, 1263 "竢其民産之有恒 … 然後惟命", 1264 친조, 1267 일본). 그 대가로 "卿先後食言，多矣"(1267, 쿠빌라이), "敷奏不實可乎"(1271) 소리를 들었다. → **"말로 시간을 번 왕"**. 업적(1259 쿠빌라이 선택, 1270 혼인 청, 무신 정권의 끝, 고려의 나라 이름과 풍속 유지 "衣冠從本國之俗")이 모두 이 방식에서 나온다.
- 후보 B — 사신 찬의 "舍近之遠"(가까운 것을 버리고 먼 것을 택했다): 1259 아릭부케 대신 쿠빌라이, 1268 곁의 김준 대신 바깥의 황제, 1270 강화 대신 개경. **"먼 쪽에 건 왕"**.
- 중심 질문(왜 그랬나): 아버지 고종에게 물려받은 것은 '참고 기다리며 버티는 법'(고종 사신 찬 "小心守法，包羞忍恥")과 '권신 밑의 왕' 자리. 스물셋에 왕이 될 아들을 둔 마흔에 처음 바깥에 나갔고, 아버지의 부고를 남의 나라 길에서 들었다. 고려 안에는 그를 지킬 칼이 없었다(김준·임연·삼별초는 모두 권신의 칼) — 그래서 바깥(쿠빌라이)의 힘을 빌려 안의 칼을 꺾었다고 이해할 수 있다(≈ 풀이).
- 흠(사료):
  - 1260.12 "王聚宮女于水房，滛縱無節" · 1260 책봉·혼례 비용 "金銀千餘斤" · 국상 중 팔관회 음악.
  - 1260 경창궁주의 말에 맏아들(충렬)을 "頗信之"(의심).
  - 1267~1268 이장용을 "疑有二心"으로 귀양 보내려 함.
  - 1267 일본 사행을 미루고 꾸밈 → "卿先後食言，多矣"; 1271 "敷奏不實".
  - 1268 김준 제거를 폐행(강윤소)·환관·임연에게 맡김 → 임연이 이듬해 그를 폐위. "眞忠臣也！"라 부른 사람이 칼을 돌렸다.
  - 1270.1 행성 앞에서 폐위의 진실을 감추고("如表所奏"), 사실을 말할 이장용을 데려가지 않음.
  - 1270 원 군대를 청해 권신을 없앰("因除權臣") → 두련가 군의 강화 약탈·방화, 동녕부(서북면 상실), 삼별초 봉기 — 백성이 값을 치름.
  - 1271 권신의 땅을 총신에게 나눠 주고 거두자는 재추에게 "大怒".
  - 사신 찬: "溺於宴安 … 媵嬙蠱其心志，閹人專其出納".
  - 1274 결혼도감(140명), 조선 3만 5백 명 — 왕이 막지 못한 것(직접 지시는 원, 집행은 고려 조정).

## 막 후보
**1막 — 1259 육반산, 어느 쪽으로 갈 것인가** (마흔)
- 상황: 몽케(헌종)를 만나러 가던 길에 몽케가 죽었다. 막내 아릭부케는 북쪽(화림)에서 군대를 막고, 동생 쿠빌라이는 남쪽 전선에 있다. "諸侯虞疑，罔知所從"(제후들이 누구를 따를지 몰랐다). 고국에선 아버지가 위독했다(고종 1259.6 죽음 — 원종은 아직 모름).
- 선택지(실제와 다른 것): ① 몽골의 본거지 쪽, 북쪽의 아릭부케에게 간다 ② 연경에 머물며 누가 이기는지 지켜본 뒤 움직인다.
- 실제: "王遂南轅閒關，至梁楚之郊" — 남쪽으로 내려가 쿠빌라이를 길가에서 맞음. 쿠빌라이 "高麗萬里之國 … 今其世子，自來歸我，此天意也"(권25, 1260.3 기사 안).
- 누가 무엇을: 쿠빌라이(위) / 조양필 "是不勞一卒，而得一國也" / 사신 찬 "舍近之遠". 원종 자신의 이유를 말한 기록은 ✘ — '먼저 묻기'에 원종 대사 쓰지 말 것. 앞 장면으로 송길대왕과의 말("大王之言，其可信乎？")·호천 큰물("太子不聽遂行")을 쓸 수 있음.

**2막 — 1268 김준이 "사신을 죽이고 바다 깊이 들어가자" 할 때** (마흔아홉)
- 상황: 쿠빌라이가 군사·전함과 함께 김준 부자의 입조를 명함. 김준은 차송우의 말에 따라 몽골 사신을 죽이고 섬 깊이 들어가자고 두 번 아뢴다. 김준은 아버지 대에 최의를 죽여 왕정을 돌려준 사람이고, 1260 왕위 계승 때도, 1264 친조 때도 그를 지켰다.
- 선택지: ① 김준의 뜻대로 몽골과 다시 싸운다 ② 김준을 그대로 두고, 그가 몽골에 불려 가 벌을 받게 내버려 둔다.
- 실제: "再白王，王不聽"(권130) → 임연·환관과 몰래 김준을 죽임(1268.12 정유 "誅金俊，夷其族", 권26).
- 누가 무엇을: 김준 "上固拒，奈何？" / 차송우 "龍孫不但今上，諸王固多" / 왕 "旣奪而復獻，於義可乎？" / 임연 "王如有命，臣豈惜死？" → 왕 "眞忠臣也！" / "王恐事泄，終夜不寐". 이 '충신'이 7개월 뒤 왕을 폐함 → 에필로그·deep 연결.

**3막 — 1270.2 연경, 황제에게 무엇을 청할 것인가** (쉰하나)
- 상황: 임연에게 폐위됐다가 몽골의 압박으로 겨우 복위. 임연은 살아 있고 강화에는 삼별초가 있다. 세자는 곁에 있다. 동녕부로 서북면도 떨어져 나가려 한다.
- 선택지: ① 군대만 빌려 임연을 친다(혼인은 청하지 않는다) ② 아무것도 청하지 않고 돌아가 임연과 함께 다스린다(행성 앞에서 이미 임연 뜻대로 답했다).
- 실제: 청혼 "伏望許降公主於世子 … 小邦萬世永倚供職惟謹" + 청병 "因除權臣" (권26, 1270.2 갑술).
- 누가 무엇을: 쿠빌라이 "然今因他事來請，似乎欲速 … 然後許之" / 흑적 "王乃帝駙馬大王之父也"(1269.11) / 사신 찬 "世結舅甥之好". 쿠빌라이의 '속셈을 꿰뚫는 말'을 그대로 쓸 수 있음. 결과(제국대장공주 1274 혼인)는 충렬왕편과 이어짐.

**4막 — 1270.5 개경으로 돌아갈 것인가, 삼별초를 어떻게 할 것인가** (쉰하나)
- 상황: 임연이 죽고 임유무가 섬에서 버티다 죽었다. 몽골군이 왕을 호위해 온다. 강화에는 40년 가까이 살아온 사람들과, 권신의 칼이었던 삼별초가 있다.
- 선택지: ① 이장용이 냈던 중간 길 — "夏居松京，冬返江都"(여름은 개경, 겨울은 강화)(권102) ② 삼별초를 그대로 두고 왕의 군대로 삼는다.
- 실제: 문무양반·백성 모두 처자와 함께 출륙하게 하고 개경 환도("今之出陸，毋如舊例 … 社稷安危，在此一擧"), 5.무진 "罷三別抄" → 6.1 배중손 봉기, 진도.
- 누가 무엇을: 두련가 "如有拒命者 … 悉皆俘擄" / 재추 "君命也，敢不從乎？" / 배중손 "蒙古兵大至，殺戮人民，凡欲輔國者，皆會毬庭！" / 삼별초 김희취(1272) "玆乃我輩怨入骨髓者也". 삼별초를 영웅·반역 어느 쪽으로도 단정하지 말 것 — 『고려사』는 '叛逆'에 둠(조선 편찬자의 분류).

**5막(대안) — 1271 황제의 요구 앞에서, 무엇이라 써 보낼 것인가** (쉰둘)
- 상황: 둔전군이 쓸 소 3천 두·농기구·씨앗·군량을 내라는 명. 백성은 "皆食草實木葉". 진도엔 삼별초.
- 선택지: ① 요구한 그대로 다 거둬 바친다 ② 할 수 없다고 딱 잘라 거절한다.
- 실제: 줄인 수(소 1,010두 등)를 약속하고 "限以力盡，不令受飢"라 써 놓은 뒤, 다시 "噫此百姓，皆是皇帝之百姓"이라 호소 → 쿠빌라이 "卿一國臣民之主，敷奏不實可乎？".
- 누가 무엇을: 쿠빌라이 "旣爲一家，初無內外之閒" / 다루가치 탈타아(고려를 감싼 몽골인) "若飮此而死，則讒構爾國者，必曰高麗毒之". 축 A('말로 시간을 번 왕')를 가장 직접 보여 주는 장면 — 막보다 deep 「그는 왜 그랬을까」에 쓰기 좋음.
