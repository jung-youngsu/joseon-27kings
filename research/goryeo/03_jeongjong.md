# 고려 정종 왕요(923~949, 재위 945~949) 『고려사』 조사 노트

원문: 권2(세가 정종), 권81(병지1 — 광군), 권77(백관지 — 광군사), 권88(후비1 정종비), 권92(박술희·왕식렴·박수경·박영규), 권93(최승로), 권127(왕규).
나이: 연도 − 923(태조 6년 계미). 945 스물둘, 949 스물여섯. "壽二十七" 세는나이.

- 945.9 무신 "群臣奉王卽位。己酉，王規謀逆，伏誅。" ✔ / 왕규전 "初惠宗疾篤，定宗知規有異志，密與西京大匡式廉謀應變。及規將作亂，式廉引兵入衛，規不敢動。乃竄于甲串，遣人追斬之，誅其黨三百餘人。" ✔ / 왕식렴전 "王倚賴益重" ✔ / 박수경전 "定宗初卽位，削平內難，守卿功居多" ✔ / 박술희전 "定宗疑有異志，流于甲串，規因矯命殺之" ✔
- 946.1 "王將謁顯陵，致齊之夕，聞御殿東山松間，有呼王名，若曰：「爾堯，存恤細民，人君之要務。」" ✔ / 천고 · 사면 / "王備儀仗，奉佛舍利，步至十里所開國寺，安之。又以穀七萬石，納諸大寺院，各置佛名經寶及廣學寶" ✔
- 947 봄 서경 왕성 ✔ / 병지 "定宗二年以契丹將侵，選軍三十萬，號光軍，置光軍司。" ✔(v081) / 백관지 광군사 "定宗二年，置之" ✔(v077)
- 948.9 동여진 대광 소무개 말 700필 · 천덕전 · "忽雷雨，震押物人，又震殿西角，王大驚 … 遂不豫" · "始行後漢年號" ✔
- 949.1 신해 왕식렴 졸 ✔ / 949.3 병진 "王疾篤，召母弟昭內禪，移御帝釋院，薨。" ✔ / "王性好佛多畏。初，以圖讖，決議移都西京，徵發丁夫，令侍中權直，就營宮闕。勞役不息，又抽開京民戶以實之，群情不服，怨讟胥興。及薨，役夫聞而喜躍。" ✔
- 이제현 찬 "定宗以人君之尊，步至十里所浮屠之宮 … 一遭天譴，喪心生疾，所謂君子求福不回者，亦嘗聞其說耶。疾旣大漸，能以宗社付之親弟，不使如王規者覬覦於其間，是可嘉也已。" ✔
- 최승로 "定宗在藩邸時，早有令聞 … 定宗先認之，密與西都忠義之將，定計而爲備 … 雖由天命，亦在人謀，豈不偉歟？自定宗至今，三十有八年，其閒洪祚之不絶，亦定宗之力也。定宗旣以連枝得繼，夙夜孜孜 … 或燃燭而引見朝士，或旰食而聽斷萬機 … 及乎誤信圖讖，決議遷都。又天性剛毅，固執不移，暴徵作役，勞動人夫，雖上慮爲然，乃群情不服 … 未及西遷，永辭南面，誠可痛也。" ✔
- 후비: 문공왕후·문성왕후 박씨(승주 박영규의 딸, 문성왕후가 경춘원군 낳음), 청주남원부인 김씨 ✔ / 박영규 "况聞高麗王公，仁厚勤儉，以得民心" ✔
- 정종 자신의 말: ✘(남지 않음).
