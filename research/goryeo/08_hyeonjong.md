# 고려 현종 왕순(992~1031, 재위 1009~1031) 『고려사』 조사 노트

원문: 위키문헌 『高麗史』 — 권3(목종 끝), 권4·5(세가 현종), 권88(후비 헌정왕후·헌애왕태후·현종 후비 13명), 권90(종실 안종 욱), 권93(최항·채충순), 권94(서눌·유진·강감찬·최사위·황보유의·양규·지채문·하공진·김은부·주저·강민첨·곽원·왕가도·유소), 권123(유행간), 권127(강조·김치양), 지(권56 지리·78~80 식화·81~82 병·84~85 형법), 권24(고종 세가 — 대장경). 캐시: scratchpad/gr/ws/v004.txt …
표시: ✔ = 『고려사』 원문 확인 / ≈ = 『고려사』 밖(전승·학설·『고려사절요』) / ✘ = 『고려사』에서 찾지 못함
나이: 사건 연도 − 992(성종 11년 임진 7월 임진 출생, 권4). 993~996 사수현(사천)에서 아버지와 함께(한 살~네 살), 996 아버지 죽음 네 살, 997 개경으로 다섯, 1003 머리를 깎임 열하나, 1006 신혈사 열넷, 1009 즉위 열일곱, 1010 거란 2차·남행 열여덟, 1011 나주·환도 열아홉, 1012 친조 거부 스물, 1014 김훈·최질의 난 스물둘, 1015 서경 주살 스물셋, 1018 거란 3차 스물여섯, 1019 귀주 스물일곱, 1020 화친 스물여덟, 1029 흥료국·나성 완성 서른일곱, 1031 죽음 서른아홉. 『고려사』 "年十二"(1003)·"壽四十"(1031)은 세는나이.
주변 인물: 강감찬 — 1031년 "年八十四"(권94, 세는나이) → 948년생쯤(≈ 셈). 1010 예순둘, 1018 일흔, 1019 일흔하나. 천추태후 964년생쯤(≈, 1029 "壽六十六").

## 1. 태어남 — 아버지도 어머니도 없이 (992~1009) — 권88, 권90, 권4
- 부모: 아버지 **안종 욱**(태조의 아들, 권90) / 어머니 **헌정왕후 황보씨**(경종의 왕비, 천추태후의 동생, 권88).
- 권88 헌정왕후: 경종이 죽은 뒤 왕륜사 남쪽 사가 → 꿈 "嘗夢登鵠嶺，旋流溢國中，盡成銀海" → 점 "生子則王，有一國" → **"時安宗第與后第相近，因與往來通焉，有娠彌月，人莫敢言。"**(안종의 집과 가까워 오가다 정을 통해 아이를 가졌는데 아무도 말하지 못했다) ✔
- **992.7** 안종의 집에서 자는데 "家人積薪于庭而火之"(집 사람들이 뜰에 섶을 쌓아 불을 지름) → 성종이 달려와 사실을 앎 → 안종 유배 → **"后慚恨哭泣，比還其第，纔及門胎動，攀門前柳枝，免身而卒。"**(왕후는 부끄럽고 원통해 울다가 집 문에 이르자 진통이 와서 문 앞 버드나무 가지를 붙잡고 아이를 낳고 죽었다) ✔ — 현종의 첫날.
- 권90 안종전: 성종이 유배 보내며 **"叔犯大義，故流之，愼勿焦心。"**(숙부께서 큰 의리를 어겨 귀양 보내지만, 너무 애태우지 마십시오) ✔ / 안종의 시 "聖主一言應不改，可能終使老漁磯" ✔
- **두 살 아이의 "아빠"**: 성종이 유모를 붙여 기름 → **"兒至二歲，姆常誨之曰爺。一日成宗召見，姆抱以入，兒仰視成宗，呼云爺。就膝上捫衣襟，又再呼爺。成宗憐之，下淚曰：「此兒深慕父也！」遂送泗水以歸郁。"**(아이가 두 살이 되자 유모가 늘 '아빠'라 부르는 법을 가르쳤다. 성종이 불러 보니 아이가 성종을 올려다보며 '아빠' 하고 무릎에 올라 옷깃을 만지며 또 '아빠' 했다. 성종이 불쌍히 여겨 눈물을 흘리며 "이 아이가 아버지를 몹시 그리워하는구나" 하고 사수로 보내 욱에게 돌려주었다) ✔ 권90 ★
- 안종은 풍수에 밝음 → 현종에게 금 한 주머니 "我死，以金贈術師，令葬我縣城隍堂南歸龍洞，必伏埋" → **996 안종 죽음**(권3 성종 15년 7월 을사 "郁死于泗水縣" ✔) → 현종이 그 말대로 함, 술사 "何大忙乎？" ✔ / **997.2 개경으로** ✔ 권90.
- **사수의 두 사람**: 1012.7 무인 교서 **"朕頃在泗水，彦孝、孝質二人，扶持左右，夙著勤勞，可賜良田，以賞其勞。"**(짐이 예전에 사수에 있을 때 언효·효질 두 사람이 곁에서 붙들어 주며 일찍부터 애썼으니 좋은 밭을 주어 그 수고를 갚으라) ✔ 권4 ★ — 스무 살 왕이 네 살 때 곁에 있던 사람을 기억함.
- 대량원군 봉작 ✔. **1003 "年十二，千秋太后忌之，逼令祝髮。初，寓祟敎寺"** ✔ 권4 (권3 목종 6년 "逼大良君詢爲僧" ✔). 숭교사에서 "大星隕寺庭，變爲龍" 꿈 이야기 ✔(설화).
- **1006 삼각산 신혈사**: "太后屢遣人謀害。寺有老僧，穴地於室而匿之，上置臥榻，以防不測。" ✔ 권4 / 독을 넣은 술·떡 → 까마귀·참새가 먹고 죽음 ✔ 권88. 노승의 이름(진관)과 '진관사' 유래는 『고려사』에 없음 ✘(≈ 전승).
- 이 무렵의 시 두 편 ✔ 권4: **「溪水」 "一條流出白雲峯，萬里蒼溟去路通。莫道潺湲巖下在，不多時日到龍宮。"**(한 줄기 물이 흰 구름 봉우리에서 흘러나와 만 리 큰 바다로 길이 통한다. 바위 밑에 졸졸 흐른다 말하지 마라, 머지않아 용궁에 닿으리라) / **「小蛇」 "小小蛇兒遶藥欄 … 莫言長在花林下，一旦成龍也不難。"**(작은 뱀이 약초 울타리를 감네 … 늘 꽃숲 밑에 있다 말하지 마라, 하루아침에 용이 되기도 어렵지 않으리) ✔ — 『고려사』 편찬자가 즉위의 조짐으로 실어 둔 시(조짐 서사 ≈ 거리 두기).
- 대량원군의 구원 편지 "姦黨遣人圍逼。遺酒食，臣疑毒不食，與烏雀，烏雀斃 … 願聖上憐救" ✔ 권93 → 목종이 황보유의 등을 보냄 → 신혈사 중이 "疑爲姦黨所遣，匿不出" → 유의가 맞이하는 뜻을 다 말하고서야 나옴 ✔ 권94.
- **1009.2 기축 연총전 즉위**(열일곱) ✔. 그날 강조가 목종을 폐하고 김치양 부자·유행간 등 7명을 죽임 ✔ (목종편). 목종 시해는 **"顯宗未之知，至契丹問罪，始知之"** ✔ 권3.

## 2. 즉위 첫해 — 강조의 그늘 (1009~1010.10) — 권4
- 1009.2 경인 강조를 중대사로 ✔. 같은 달 **"罷敎坊，放宮女一百餘人，毁閬苑亭，珍禽奇獸龜魚之類，放之山澤。"**(교방을 없애고 궁녀 백여 명을 내보내며, 낭원정을 헐고 진귀한 새·짐승·거북·물고기를 산과 못에 놓아주었다) ✔ — 목종 때의 놀이를 걷어 냄.
- 1009.3 강조 이부상서 참지정사 ✔ / "議築開京羅城" ✔ / 1009.5 을해 **연흥궁주의 딸 김씨(성종의 딸, 원정왕후·현덕왕후)를 왕비로** ✔ — 원화왕후 최씨도 성종의 딸 ✔ 권88.
- 1009.7 계유 "敎文官常叅以上，各上封事，極言時政得失" ✔ / 신미 80세 이상·중병자 635명 잔치 ✔ / **최항을 사부로**: 권93 **"朕少値閔凶，未聞義訓。仰遵古典，思得其人 … 可授政堂文學，以爲寡人師傅。"**(짐은 어려서 부모를 잃는 슬픔을 만나 바른 가르침을 듣지 못했다. 옛 법을 따라 그런 사람을 얻고자 한다 … 과인의 스승으로 삼는다) ✔ ★
- 1009.12 병신 긴 교서 "子育黎庶，不敢遑寧 … 然萬機之務，獨理爲難，允資臣下之功" ✔.
- 1010.윤2 연등회 부활, 11월 팔관회 부활 ✔ — 최항의 청 ✔ 권93(성종이 없앤 것을 되살림).
- 1010.5 갑신 **하공진·유종 귀양**: 하공진이 동여진을 쳤다가 패하자 유종이 원한을 품고, 내조한 여진 95명을 화주관에서 다 죽임 ✔ → 여진이 거란에 호소 → **거란 성종 "高麗康兆弑君，大逆也，宜發兵問罪。"**(고려의 강조가 임금을 죽였으니 큰 반역이다. 군사를 내어 죄를 묻겠다) ✔
- 1010.7 거란 사신 "問前王之故" ✔ / 8월 진적·윤여를 거란에 ✔ / 10월 병오 **강조를 행영도통사로, 30만으로 통주에** ✔ / 계축 거란 출병 통고 → 이예균·왕동영 "請和" ✔.

## 3. 거란 2차 침입과 남행 (1010.11~1011.2) — 권4, 권94, 권127
- **1010.11 신묘 "契丹主自將步騎四十萬，渡鴨綠江，圍興化鎭，楊規、李守和等固守不降。"** ✔ (권127 강조전 "號義軍天兵" ✔). 40만은 『고려사』 숫자 → 게임에서 "40만이라 적혀 있습니다"로 거리.
- 권94 양규전: 거란 성종의 화살 편지 "朕以前王誦，服事朝廷 … 今逆臣康兆，弑君立幼 … 汝等擒康兆，送駕前，便卽回兵，不然直入開京，殺汝妻孥" ✔ / 거란이 강조 이름으로 가짜 항복 편지 → **양규 "我受王命而來，非受兆命。"**(나는 왕명을 받고 왔지 강조의 명을 받은 것이 아니다) ✔
- **1010.11 기해 통주 패전**: 강조가 검차로 몇 번 이기자 "遂有輕敵之心，與人彈棊"(적을 얕보고 바둑을 둠) → "如口中之食，少則不可宜，使多入" → 사로잡힘 ✔ 권127 / 환영의 목종 "汝奴休矣。天伐詎可逃耶？" ✔(설화적) / **거란 성종 "汝爲我臣乎？" → 강조 "我是高麗人，何更爲汝臣乎？"**(나는 고려 사람인데 어찌 다시 네 신하가 되겠느냐) — 세 번 같은 대답, 처형 ✔ / 이현운 "兩眼已瞻新日月。一心何憶舊山川？" → 강조가 걷어참 ✔ / "斬首三萬餘級" ✔ 권94.
- 곽주 함락, 안북도호부사 박섬 도망, 숙주 함락 ✔ / 서경: 권94 지채문전 — 부유수 원종석 등이 이미 항복 표문을 씀 → 최창·지채문이 거란 사자를 죽이고 표문을 태움 ✔ / 탁사정이 대도수를 속이고 밤에 달아남 → 대도수 항복 ✔ / 조원·강민첨 등이 "共禱神祠，筮得吉兆" 하고 성을 지킴 ✔ / 거란이 서경을 못 빼앗고 동쪽으로 ✔ 세가 신유.
- **남행 결정** ✔ ★
  - 권94 강감찬전: **"契丹主自將攻西京，我軍敗報至，群臣議降。邯贊獨曰：「今日之事，罪在康兆，非所恤也。但衆寡不敵，當避其鋒，徐圖興復耳。」遂勸王南幸。"**(신하들은 항복을 의논했으나 강감찬만이 "오늘 일은 강조의 죄이니 걱정할 것이 아닙니다. 다만 수가 맞서지 못하니 그 칼끝을 피하고 천천히 다시 일어설 길을 찾아야 합니다" 하고 남쪽으로 갈 것을 권했다)
  - 지채문 "臣雖駑怯，願在左右，效犬馬勞。" → 왕 **"昨李元、崔昌奔還，自請扈從，今不復見，爲臣之義，果如是乎？今卿旣勞于外，又欲捍衛，予甚嘉之。"**(어제 이원·최창이 돌아와 따르겠다 해 놓고 지금 보이지 않으니 신하의 도리가 이런 것인가. 경은 밖에서 애쓰고 또 지키겠다 하니 매우 기쁘다) ✔ 권94
  - 1010.12 임신 밤 "王與后妃，避丹兵南幸" ✔ 권4 (원문은 11월 기사에 이어 '十二月'이 빠져 있으나 간지로 보면 12월) / "率禁軍五十餘人，出都" ✔ 권94.
- **피란길** ✔ 권94 지채문전 — 하나하나 장면 재료
  - 적성현 단조역: 무졸 견영과 역 사람들이 행궁을 범하려 함 → 지채문이 활로 물리침.
  - 창화현: 아전이 **"王識吾名面乎？"**(왕은 내 이름과 얼굴을 아시오?) → "王陽不聞"(왕이 못 들은 척함) → "河拱辰將兵來矣" 소문 → 김응인·이정충 등 도망, **"獨蔡文、忠順、周佇等留侍"** / 밤에 도적이 또 오자 "侍從臣僚、宦官、嬪御皆亡匿，唯玄德、大明二王后，侍女二人 … 侍".
  - 도봉사로 숨음 → 지채문이 하공진을 확인하러 가겠다 → 왕이 그가 달아날까 걱정 "不許" → 채문 "臣若背君，言與事違，天必誅之" → 허락 ✔ (흠이 아니라 두려움).
  - **하공진의 계책**: **"契丹本以討賊爲名，今已得康兆，若遣使請和，彼必班師。"**(거란은 본래 역적을 친다는 명분이었으니 이제 강조를 잡았으므로 사신을 보내 화친을 청하면 반드시 군사를 돌릴 것입니다) → "王筮得吉卦，遂遣拱辰" ✔ / 거란 선봉에게 "國王安在？" → **"今向江南，不知所在。" "江南太遠，不知幾萬里。"**(지금 강남으로 가셨는데 어디인지 모릅니다. 강남은 너무 멀어 몇 만 리인지 모릅니다) → "追兵乃還" ✔ 권94
  - 1010.12 갑술 양주에서 하공진·고영기를 거란 진영에 ✔ 세가.
- **1011.1 을해 초하루 "契丹主入京城，焚燒太廟、宮闕、民屋皆盡。"** ✔ — 같은 날 왕은 광주.
- 1011.1 정축 하공진이 붙잡혔다는 말에 **"扈從諸臣 … 皆驚懼散走，惟侍郞忠肅、張延祐、蔡忠順、周佇、柳宗、金應仁不去。"** ✔

## 7. 그 밖에 — 『고려사』 안과 밖
- **초조대장경**: 현종 때 새기기 시작했다는 기사 ✘(세가·지에 없음). 『고려사』 권24 고종 38년 9월 **"顯宗時板本，燬於壬辰，蒙兵"**(현종 때 판본이 임진년 몽골 군사에 불탔다) ✔ — 현종 때 판본이 있었다는 간접 증거. 거란을 물리치려 새겼다는 동기는 이규보 「대장각판군신기고문」(『동국이상국집』) ≈. 1029.4 회경전 장경도량 ✔(관련 여부 ≈).
- **7대 실록**: 1013.9 병진 최항 감수국사, 김심언 수국사, 주저·윤징고·황주량·최충 수찬관 ✔ — 완성 기사 ✘(『고려사』 세가에서 찾지 못함, 덕종 때 완성설 ≈).
- 『고려사절요』의 남행 기사와 세가·지채문전의 날짜 대조 ≈ — 절요는 열어 보지 않음.

## 8. 평가 — 누가 썼나
- 권5 **사신 최충 찬**(현종 때 사관, 고려 당대): "天之將興，誰能廢之？ … 然以姨母貽孽，戎臣構逆，强鄰伺釁，京闕俱燼，乘輿播遷，艱否極矣，反正之後，和戎結好，偃革修文，薄賦輕徭，登崇俊良 … 比之周之成、康，漢之文、景，亦無愧矣。"(이모가 화를 남기고 무신이 반역하고 강한 이웃이 틈을 엿보아 궁궐이 다 타고 임금이 떠도는 고생이 극에 이르렀다. 바로잡은 뒤에는 오랑캐와 화친하고 무기를 거두고 글을 닦았으며 세금과 부역을 가볍게 하고 인재를 높였다 … 주나라 성왕·강왕, 한나라 문제·경제에 견주어도 부끄럽지 않다) ✔ — 자기 왕을 칭찬하는 당대 기록 + 천추태후는 악역.
- **이제현**(고려 말): "崔冲之言，世所謂命也 … 人君恃有天命，縱欲敗度，雖得之，必失之 … 如顯宗，所謂『吾無閒然者』乎。"(최충의 말은 이른바 하늘의 뜻을 말한 것이다. 임금이 천명을 믿고 욕심대로 하면 얻어도 반드시 잃는다 … 현종 같은 이는 '나는 흠잡을 데가 없다'고 할 만한 사람이 아니겠는가) ✔ — 천명이 아니라 행동으로 평가하자는 말. 조선 편찬자는 별도 평을 달지 않음. → 칭찬 일색이므로 흠은 사실 기사에서 직접 찾아야 함(§4·§6).

## 축(제안)
- **"朕少値閔凶，未聞義訓"(어려서 부모를 잃어 바른 가르침을 듣지 못했다) → "부모 대신 곁의 사람에게서 배운 왕"**. 태어난 날 어머니가 죽고, 네 살에 아버지가 죽고, 열한 살에 머리를 깎이고, 열넷에 독 든 떡을 받음. 그래서 사람을 붙든다: 스승을 청하고(최항), "且無面從"(앞에서만 따르지 말라)을 말하고, 반대하는 강감찬의 말을 듣고, 남은 사람을 기억한다(사수의 언효·효질, 지채문 "終保松筠之節", 양규의 아내에게 손수 교서, 강감찬의 금꽃과 시, 길에서 죽은 군사의 뼈를 집으로). 생일 잔치를 금한 까닭도 "寡人早値閔㓙". 그리고 남의 말을 듣는 그 성질이 흠도 됨 — 김훈의 요구에 "重違衆志", 왕가도의 "雲夢之遊"에 "納之", 곽원의 말에 제 생각을 접음.
  - 중심 질문 연결: 물려받은 것이 아버지의 가르침이 아니라 *버려진 경험*. "그래서 곁에 남는 사람을 그토록 아낀 것이 이해된다."
- 다른 한 줄 후보: 1024 **"寡人有過，請卽降罰，萬民有過，寡人亦當之"** / 1018 **"當時不用姜公策，擧國皆爲左衽人"**(자기 선택을 스스로 돌아본 말).
- 흠: 남행 길에 아전 앞에서 "陽不聞", 지채문이 달아날까 의심, "將軍言是也" 해 놓고 결국 임신한 왕후를 떼어 보냄("勢不獲已"), 큰일마다 점에 기댐, 친조 약속을 '병'으로 핑계, 박섬처럼 도망쳤다 돌아온 자에게 벼슬("時議譏之"), 무신 반란 앞에서 죄 없는 신하를 귀양 보냄, 1년 뒤 잔치 자리에서 19명을 죽인 함정(雲夢之遊), 즉위시켜 준 강조 일당을 2년 뒤 섬으로, 현화사에 둔전 1,240결(두 성 반대 "不納"), 중광사 공사로 백성·승려 징발, 성종의 두 딸·김은부의 세 딸 등 후비 13명(권88) — 혼인으로 사람을 묶음.

## 막 후보
1. **1010.12 — 떠날 것인가, 항복할 것인가** (열여덟) ★ 중심
   - 상황: 강조가 통주에서 잡히고 서경이 흔들림. 거란은 "강조를 잡으려 왔다"는 명분. 신하들은 항복을 의논.
   - 하지 않은 길: ① 항복 표문을 올리고 거란 진영에 나간다 ② 개경에서 끝까지 지킨다.
   - 실제: 강감찬의 말 "當避其鋒，徐圖興復耳"를 따라 밤에 금군 50여 명과 남쪽으로 + 하공진을 보내 화친을 청함(두 길을 동시에) ✔ 권94
   - 말: 강감찬 "今日之事，罪在康兆，非所恤也" / 하공진 "契丹本以討賊爲名，今已得康兆，若遣使請和，彼必班師" / 지채문 "臣雖駑怯，願在左右" ✔
2. **1011.1 — 왕후를 고향으로 보낼 것인가** (열아홉)
   - 상황: 신하들이 흩어지고, 유종·김응인이 두 왕후를 각자 고향으로 보내고 호위 장졸도 동쪽으로 돌리자 함.
   - 하지 않은 길: ① 짐을 덜기 위해 두 왕후를 보낸다 ② 아무 말 없이 따른다.
   - 실제: 지채문에게 묻고 "將軍言是也" — 함께 감. 그러나 며칠 뒤 임신한 현덕왕후는 "勢不獲已" 하고 선주로 보냄 ✔ 권94 — 정답 없는 막.
   - 말: 지채문 "弃王后以求生，其可忍乎？" ✔
3. **1012.6 — 거란에 직접 갈 것인가** (스물)
   - 상황: 철군 조건이 왕의 친조. 거란이 "親朝"를 부름. 개경은 불탔고 성 쌓기는 이제 시작.
   - 하지 않은 길: ① 약속대로 거란에 들어간다 ② 대신 국경의 여섯 성을 내준다.
   - 실제: 사신을 보내 "王病，不能親朝" → 6성 요구도 끝내 거절, 송에 사신(1014·1015), 국경 성을 버팀 ✔ 권4
   - 말: 기록된 신하의 찬반 대화는 ✘ — '먼저 묻기'에 쓸 실제 대사 없음. 거란 쪽 "詔取興化 … 六城" ✔만.
4. **1014.11~1015.3 — 칼을 든 장군들을 어떻게 할 것인가** (스물둘~스물셋)
   - 상황: 녹봉을 위해 군인 땅을 빼앗자 최질·김훈이 궁에 들어와 두 신하를 매질. 무관이 문관을 겸하게 해 달라 함.
   - 하지 않은 길: ① 끝까지 그들의 요구를 들어주며 산다 ② 그 자리에서 맞서 진압한다.
   - 실제: 처음엔 "重違衆志" 하고 다 들어줌 → 왕가도의 "雲夢之遊" 계책을 받아들여, 1년 뒤 서경 장락궁 잔치에서 취한 틈에 19명을 죽임 ✔ 권4·권94 — 현종의 '뒤의 얼굴'.
   - 말: 무관 "諸軍洶洶，不勝憤怨，請除國蠹" / 왕가도 "王何不效漢高雲夢之遊乎？" ✔
5. **1018.12~1019.1 — 이번에도 떠날 것인가** (스물여섯)
   - 상황: 소손녕이 서울 백 리 앞 신은현까지. 8년 전엔 떠났고, 궁궐과 태묘가 탔다.
   - 하지 않은 길: ① 다시 남쪽으로 피한다 ② 성 밖으로 군사를 내어 맞붙는다.
   - 실제: 태조의 관을 미리 옮기고 계엄, "收城外民戶入內，淸野以待" — 남아서 들을 비움. 강감찬이 1만을 보내 서울을 지킴 → 귀주 ✔ 권4·권94
   - 에필로그/다음 장면: 영파역 금꽃 / "請稱藩納貢如故"(1020) — 이기고도 화친을 고른 것 / 1029 흥료국 원병 거절("兵者危事").
